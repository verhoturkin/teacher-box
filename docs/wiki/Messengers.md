# Мессенджеры

Уведомления всегда видны в личном кабинете. Мессенджеры подключаются по желанию: «Уведомления» →
«Мессенджеры» → «Подключить». Мастер подскажет, как создать бота, проверит токен, подключит ваш
аккаунт и пришлёт тестовое сообщение — перезапускать портал не нужно. Боты получают сообщения
сами (long polling) — публичный адрес для вебхуков не нужен. Ученики подключают мессенджер у
себя в разделе «Уведомления»; кто уже подключил, видно в секции «Ученики», там же можно
напомнить остальным. В секции «Что присылать» каждый выбирает темы уведомлений для мессенджеров
и тихие часы.

Токены можно задать и переменными окружения (ниже) — тогда они важнее настроек из интерфейса.

## Telegram

1. Напишите [@BotFather](https://t.me/BotFather) команду `/newbot`, задайте имя и адрес бота.
2. Вставьте токен в мастер (или в `TEACHERBOX_NOTIFICATIONS_TELEGRAM_BOT_TOKEN`).

## ВКонтакте (сообщения от имени сообщества)

1. Создайте сообщество (можно закрытое) → «Управление» → «Сообщения»: включите.
2. «Работа с API» → «Ключи доступа»: создайте ключ с правом «Сообщения сообщества» — это
   токен (`TEACHERBOX_NOTIFICATIONS_VK_TOKEN`).
3. «Работа с API» → «Long Poll API»: включите, версия API 5.199, в «Типах событий» отметьте
   «Входящее сообщение».
4. «Сообщения» → «Настройки для бота»: включите «Возможности ботов» — иначе под сообщениями не
   будет кнопок меню.
5. Номер сообщества — цифры из `club123456` (`TEACHERBOX_NOTIFICATIONS_VK_GROUP_ID`).

## MAX

1. Создайте бота на платформе MAX для партнёров ([dev.max.ru](https://dev.max.ru)).
2. Токен бота — в мастер (или в `TEACHERBOX_NOTIFICATIONS_MAX_TOKEN`).

Чтобы ссылки в сообщениях вели на портал, задайте адрес портала: «Настройки» → «Портал» (или
`TEACHERBOX_PUBLIC_URL`).

## Действия через бота

Кроме уведомлений, бот показывает меню кнопками: напишите ему `/menu`.
`/cancel` отменяет начатое действие, `/help` — подсказка, `/stop` отключает уведомления. Если к
одному чату подключено несколько учеников (например, у родителя), бот спросит, от чьего имени
действовать. Перед любым изменением бот просит подтверждение.

Ученику бот показывает расписание со ссылкой на ближайший урок, ссылки на видеовстречи и доски,
баланс и последние оплаты; через бота ученик просит отменить или перенести занятие (выбирает
занятие, новый день и время, пишет комментарий), в групповом занятии сообщает «не приду», видит
ответы учителя на свои запросы и может отозвать запрос без ответа.

Учителю бот показывает занятия на сегодня и прошедшие без отметки — их можно отметить
(«Проведено», «Пропуск», у группы — кто был); запросы учеников — принять (позднюю отмену —
засчитать как пропуск или нет) или отклонить с ответом, кнопки есть и прямо под уведомлением о
запросе; через бота учитель записывает оплату (1, 4 или 8 занятий по цене ученика или любую сумму)
и добавляет в журнал занятие, проведённое вне расписания, — с учеником или с группой. Что умеет бот, видно в секции
«Мессенджеры»; там же можно выключить управление порталом через бота для учителя (уведомления
продолжат приходить). Подробнее —
[ADR-0013](https://github.com/verhoturkin/teacher-box/blob/main/docs/adr/0013-bot-dialogs.md).

Из России Telegram Bot API недоступен — нужен [прокси](Proxy).
