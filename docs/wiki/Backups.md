# Резервные копии и восстановление

Копии создаются каждую ночь в `/data/backups` и хранятся `TEACHERBOX_BACKUP_KEEP_DAYS` дней (по
умолчанию 14): более старые копии любого вида — и на сервере, и в Google Диске — удаляются после
создания новой. Срок меняет администратор: «Настройки» → «Резервные копии» → «Сколько дней хранить
копии». Создать, скачать или восстановить
копию — «Настройки» → «Данные» → «Резервные копии» (администратору — раздел «Копии», без скачивания).
Перед восстановлением портал сам делает копию текущего состояния и перезапускается. «Полный
сброс» в «Настройках» удаляет все данные, кроме входа учителя и администратора и резервных копий
(перед ним тоже делается копия). Копии можно автоматически отправлять в Google Диск учителя
(«Настройки» → «Данные» → «Google Диск»; нужен свой OAuth-клиент Google с Google Drive API — пошагово
в панели и в
[эксплуатации](https://github.com/verhoturkin/teacher-box/blob/main/docs/operations.md#копии-в-google-диске)).
Подробно —
[эксплуатация](https://github.com/verhoturkin/teacher-box/blob/main/docs/operations.md).

## Удалить все данные на сервере

Начать с чистого листа, как после новой установки:

```bash
sudo teacherbox reset
```

Команда удаляет из Docker контейнеры и тома портала — базу, файлы, резервные копии на сервере,
настройки из интерфейса, учётные записи, сертификаты HTTPS — и запускает портал заново: создаётся
учитель с новым паролем (команда его напечатает), открывается первоначальная настройка. Остаются
`compose.yaml`, `.env` и образы; копии в Google Диске не трогаются. Команда просит ввести слово
«УДАЛИТЬ» (`--yes` — без вопроса). Нужные копии сохраните заранее: `sudo teacherbox backups`.
