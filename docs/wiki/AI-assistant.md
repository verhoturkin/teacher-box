# ИИ-помощник

По умолчанию выключен. Учитель подключает его сам: «Настройки» → «ИИ-помощник» → «Подключения» →
«Добавить» — провайдер (Anthropic, Gemini, OpenRouter, DeepSeek или OpenAI-совместимый сервер),
API-ключ, «Проверить и продолжить», затем модели из списка провайдера или вручную по
идентификатору. Подключений и моделей может быть несколько; черновики пишет модель по умолчанию
(переключатель у модели в списке). Там же месячный лимит токенов — общий для всех подключений, 0 —
без лимита. Если провайдер недоступен из сети сервера, у подключения можно указать свой прокси
(«Дополнительно»), иначе действует общий `TEACHERBOX_AI_PROXY`, его меняет администратор без
перезапуска ([Прокси](Proxy)).

## Какое подключение выбрать

Одного хватит: добавьте то, чей ключ у вас уже есть. Второе подключение нужно, когда разным задачам
подходят разные модели (мощная для проверки работ, быстрая для черновиков заданий) или нужен
запасной провайдер на случай сбоя.

- **Anthropic, Gemini, DeepSeek** — свой ключ у каждого провайдера, расход виден в его кабинете.
- **OpenRouter** — модели многих компаний по одному ключу; удобно пробовать и сравнивать.
- **OpenAI-совместимый сервер** — OpenAI или свой Ollama: с Ollama ключ не нужен и тексты не
  покидают вашу сеть.

## Прокси у каждого подключения

Прокси задаётся подключению отдельно («Дополнительно»): если один провайдер недоступен из сети
сервера (например, Gemini из России), прокси указывают только ему, остальные ходят напрямую. Без
своего прокси подключение использует общий `TEACHERBOX_AI_PROXY` администратора ([Прокси](Proxy)).

## Выбор модели при работе

Когда моделей несколько, другую можно выбрать прямо там, где пишет ИИ: кнопка с названием модели
стоит рядом с «Сгенерировать» (при проверке работы и в итогах занятия — рядом с кнопкой черновика).
Выбор запоминается на этом устройстве; если модель удалили, черновики снова пишет модель по
умолчанию.

Переменные ниже нужны только тем, кто уже настроил ИИ в `.env` в прошлых версиях: при **первом**
запуске новой версии портал один раз переносит их в «Настройки» — сервис становится первым
подключением, а его модель основной — и дальше эти переменные не читает (см.
[Обновление](Update)); всё остальное меняется в «Настройках».

```ini
# Claude (Anthropic): ключ — на console.anthropic.com
TEACHERBOX_AI_PROVIDER=anthropic
TEACHERBOX_AI_API_KEY=sk-ant-...
# модель по умолчанию — claude-opus-5

# или Google Gemini: ключ Gemini API — на aistudio.google.com («Get API key»)
TEACHERBOX_AI_PROVIDER=gemini
TEACHERBOX_AI_API_KEY=AIza...
# модель по умолчанию — gemini-3.8-flash

# или OpenRouter: ключ — на openrouter.ai/keys, модели разных компаний по одному ключу
TEACHERBOX_AI_PROVIDER=openrouter
TEACHERBOX_AI_API_KEY=sk-or-...
# модель по умолчанию — openrouter/auto (OpenRouter выбирает её сам);
# конкретная — по названию с openrouter.ai/models, например TEACHERBOX_AI_MODEL=deepseek/deepseek-v4

# или DeepSeek: ключ — на platform.deepseek.com
TEACHERBOX_AI_PROVIDER=deepseek
TEACHERBOX_AI_API_KEY=sk-...
# модель по умолчанию — deepseek-flash; посильнее — deepseek-v4-pro

# или OpenAI-совместимый сервис
TEACHERBOX_AI_PROVIDER=openai-compatible
TEACHERBOX_AI_BASE_URL=https://api.openai.com/v1
TEACHERBOX_AI_API_KEY=sk-...
TEACHERBOX_AI_MODEL=gpt-5

# или локальная модель в Ollama (ключ не нужен)
TEACHERBOX_AI_PROVIDER=openai-compatible
TEACHERBOX_AI_BASE_URL=http://ollama:11434/v1
TEACHERBOX_AI_MODEL=qwen3:14b

TEACHERBOX_AI_MONTHLY_TOKEN_LIMIT=2000000
```

Как только выбрана модель по умолчанию, в редакторе задания появится «ИИ-помощник» («Написать с
ИИ»), а на странице проверки — «Черновик проверки».
В широком окне помощник находится справа от редактора и занимает половину доступной ширины; в узком открывается отдельной панелью
по кнопке «ИИ-помощник». Запрос, источники и черновик сохраняются при закрытии панели и изменении
ширины окна. «Текст / Просмотр» переключает одно поле задания; помощник доступен в обоих режимах. Тексты уходят провайдеру только по вашему нажатию; ответ ИИ
всегда черновик, который вы правите сами. Расход, последние запросы,
библиотека промтов и системные промты — в «Настройки» → «ИИ-помощник».

В итогах занятия (карточка занятия в расписании) кнопка «Черновик» у поля «Что прошли» составляет
итоги по теме занятия, выданным на нём заданиям и вашим коротким словам; результат — черновик,
который вы правите сами. Её системный промт — в «Настройки» → «ИИ-помощник».

Вопросы для теста тоже можно составить с помощником: в панели ИИ в редакторе задания переключите
«Что готовить» на «Вопросы», опишите, что нужно, при желании выберите источники (учебник, файл,
видео) — придёт черновик вопросов с верными ответами. «Добавить в конец» или «Заменить все» переносит
его в карточку «Вопросы»; проверьте ключ и сохраните задание. Системный промт этой функции — в
«Настройки» → «ИИ-помощник».

Теги учеников подсказывают ИИ, для кого пишется текст. В «Настройки» → «Ученики» → «Теги учеников»
создайте тег (например, «Уровень английского» со значениями A1–C2; можно начать с шаблона) и
оставьте включённым «Учитывать в ИИ». Если у каждого ученика своё — увлечения, особенности, —
выберите тип «Свободный текст» (шаблон «Интересы»): в карточке ученика тогда пишется текст до 120
символов, например «футбол, Minecraft», и ИИ берёт примеры из него. Тип тега нельзя поменять, пока
тег задан хотя бы у одного ученика. Значение тега выбирается в карточке ученика, на вкладке «Теги»;
там же блок «Что увидит ИИ» показывает, что уйдёт в запрос. Когда вы составляете задание, тест или
черновик проверки, над запросом появляются чипы «Учитываю об учениках»: ИИ подбирает сложность и
стиль под эти значения. Если выбраны несколько учеников с разными значениями или текстами, чип
подсвечен — нажмите на него и выберите одно значение. Если все тексты вместе длиннее
120 символов, ИИ получает самый частый, пока вы не выберете другой. Чтобы не учитывать тег в
одном запросе, уберите его чип «×»; чтобы не учитывать совсем — выключите «Учитывать в ИИ» у тега
(по тегу со списком значений всё равно можно фильтровать список). Теги — значения по умолчанию: если в запросе вы просите другое, ИИ следует
запросу. Теги видны только вам; ученикам, ботам и администратору они не показываются, а ИИ
получает только название и значение, без имени ученика.

Про Gemini: подписка Google AI Pro к порталу не подключается — она действует только в
приложении Gemini и в веб-интерфейсе AI Studio, а обращения программ к Gemini API оплачиваются
отдельно (есть бесплатный уровень с дневными лимитами). На бесплатном уровне Google может
использовать тексты запросов для улучшения своих продуктов, а в запросах на проверку бывают
ответы учеников — для них лучше включить оплату в AI Studio. Из России Gemini API недоступен,
нужен прокси (см. [Прокси](Proxy)).

Про OpenRouter: запросы уходят только тем поставщикам модели, которые соблюдают формат ответа
портала. Расход и баланс видны в кабинете OpenRouter; там же, в настройках приватности, можно
запретить поставщиков, которые сохраняют запросы или учатся на них (бесплатные модели этого
обычно требуют) — в запросах на проверку бывают ответы учеников.

Видео задания ИИ «смотрит» по расшифровке: в редакторе нажмите «Настроить» у плитки видео — в окне
есть «Расшифровка» и кнопки «Субтитры YouTube» и «Из файла» (.srt / .vtt). Если у ролика несколько
дорожек субтитров, откроется меню: язык и «от автора видео» или «автоматические». Отметьте видео в
«Опереться на» — модель получит расшифровку с метками времени, это работает с любым провайдером,
в том числе с DeepSeek, который читает только текст. Сам ролик модели не передаётся. Субтитры
YouTube портал берёт неофициальным путём: если YouTube его закроет или из России ролик не
открывается, кнопка сообщит об ошибке — укажите прокси `TEACHERBOX_HOMEWORK_YOUTUBE_PROXY`
(см. [Прокси](Proxy)) или вставьте расшифровку вручную.

Про DeepSeek: его API не принимает схему ответа, поэтому портал описывает нужный JSON в запросе
сам. Обычно доступен из России без прокси. Если DeepSeek уже подключён как `openai-compatible`, он тоже
заработает (портал сам перейдёт на подходящий формат ответа), но проще указать `deepseek`.
