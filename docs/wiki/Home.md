# Teacher Box — портал репетитора

Ученики, расписание, домашние задания, оплаты, звонки и доски в одном месте — на вашем сервере,
на компьютере и с телефона. Один учитель, без регистрации «с улицы»: ученики входят по
ссылке-приглашению и видят только своё.

Поставить портал на Linux-сервер — одна команда:

```bash
curl -fsSL https://raw.githubusercontent.com/verhoturkin/teacher-box/main/scripts/install.sh | sudo bash
```
