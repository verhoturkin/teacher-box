# Версия 1.6.12 — архив плана (этапы 76–80)

Цели: единообразие кнопок, окон, навигации, обратной связи, типографики и текстов по Material 3
Expressive и ADR-0018…0022 без изменения функционала: те же маршруты, данные, права и сценарии.

Итоги разбора (тот же аудит):

- **Кнопки.** «Отмена», «Отменить» и «Назад» — одна подпись для разных действий и цветов; в окне занятия
  до пяти кнопок, три красные, начальный фокус — на «Удалить»; на странице по нескольку filled; кнопки
  форм, секций и окон не на своих местах; Enter не отправляет форму в 9 окнах; 20 действий без защиты от
  двойного нажатия; кнопки 42 px вместо 40.
- **Окна.** Подтверждения растягиваются до 1 127 px, ширины окон — по месту, окна с одним полем пароля на
  телефоне — во весь экран.
- **Навигация.** Шесть пунктов нижней панели, «Расписан…» обрезано, раздел из «Ещё» не отмечен; 404 вне
  каркаса; меню, h1 и вкладка называют страницу по-разному.
- **Обратная связь.** После частых действий нет тоста; пустые состояния четырёх видов, с дублями FAB.
- **Типографика и тексты.** У заголовков карточек и окон нет своей высоты строки, вес 600; справка
  расходится с экраном; одно понятие — разные слова; учителю показывают имена переменных окружения;
  восемь масок дат.
- **Списки.** Строки данных — своими разметками, таблицы ниже 56 px, статусы разной формы,
  «Подключиться» скачет.

## Этап 77. Кнопки и окна

- [x] 77.1 **F** Подписи и цвета решений по ADR-0026: одна подпись для закрытия окна, «Отменить
      занятие…», «Удалить…», «Снять начисление»; окно занятия — главное действие в подвале, остальное в
      меню; начальный фокус — не на опасной кнопке.
- [x] 77.2 **F** Одна filled-кнопка на странице; цвет по смыслу; действия строк — text.
- [x] 77.3 **F** Кнопки форм, секций и окон на своих местах (`tb-form-actions`, действия в строке
      заголовка карточки, подвал с `button[form]`); Enter отправляет форму; `[loading]` у действий,
      отправляющих запрос.
- [x] 77.4 **F** Окна: классы ширины вместо inline-стилей, подтверждения до 35 rem с полями от краёв,
      короткие окна на телефоне — обычные.
- [x] 77.5 **F** Кнопки 40 px везде, «Добавить» в карточках — 40 px; у кнопок-значков подсказка
      совпадает с именем, имя — с контекстом строки.

## Этап 78. Навигация и обратная связь

- [x] 78.1 **F** Нижняя панель по ADR-0027: четыре раздела и «Ещё», раздел из «Ещё» отмечает «Ещё»;
      индикатор раздела в панели и rail — пружиной.
- [x] 78.2 **F** 404 внутри каркаса роли; меню, h1 и заголовок вкладки называют страницу одинаково,
      вложенная страница — своим именем; «Назад» подписан местом, куда ведёт.
- [x] 78.3 **F** Тост после частых действий (занятие, группа, ответ на запрос, отметка); пустые состояния
      — только `tb-empty-state` (компактный вариант для виджетов и календаря), без кнопки, если та же —
      FAB.
