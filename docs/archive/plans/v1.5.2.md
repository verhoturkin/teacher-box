# Версия 1.5.2 — архив плана (этапы 49)

Цели: исправить ошибки интерфейса, найденные после выпуска 1.5.1.

Итоги разбора:

- **Ученик в диалогах «Оплат»** не выбирается: форма сбрасывается в эффекте без `untracked`, а
  `p-select` при записи значения читает свой сигнал `modelValue()` — эффект подписывается на него и
  при выборе ученика сбрасывает форму снова. В расписании сброс уже в `untracked`.
- **Запись занятия в «Оплатах»** дублирует расписание: занятия списываются по отметке в расписании.
- **Кнопки диалога занятия** в календаре учителя: у начавшегося занятия их до пяти («Удалить»,
  «Отменить», «Изменить», «Пропуск», «Проведено»), а подвал диалога не переносит их на новую
  строку — они выходят за край.
- **Пункты меню** в шапке и в меню пользователя подчёркиваются при наведении: общее правило для
  ссылок задевает ссылки пунктов PrimeNG.
- **Занятое время** в календаре ученика — серый фон без подписи: непонятно, что он означает.
