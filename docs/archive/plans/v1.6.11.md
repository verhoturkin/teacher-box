# Версия 1.6.11 — архив плана (этапы 72–75)

Цели: сорванные сценарии, контраст и доступность (WCAG 2.2 AA) по итогам аудита интерфейса 2026-09-29 без
изменения функционала: те же маршруты, данные, права и сценарии.

Итоги разбора (аудит [`docs/archive/audit/design-audit-2026-09-29.md`](../audit/design-audit-2026-09-29.md): три роли,
320–1920 px, обе темы, цвета портала, крупный шрифт, медленная сеть и ошибки):

- **Сорванные сценарии.** Окна в раскрытых секциях «Уведомлений» заперты внутри секции — мастер бота на
  телефоне недоступен. Ошибка загрузки выглядит как «ничего нет», сверху — стопка одинаковых тостов,
  загрузка без индикатора. «Уведомления» ученика на 360 px шире экрана, выпадающие списки и правка цены
  раздвигают страницу.
- **Контраст.** Статусы, сообщения, предупреждения и события календаря — цвета Aura (2,8–4,4 : 1), роли
  warning нет; красный и приглушённый прозрачностью текст ниже 4,5 : 1; код подключения в тёмной теме —
  1,09 : 1. «Бирюзовый» и «Изумрудный» — 3,7 : 1 белому на кнопке, проверка своего цвета — одна пара,
  порог 3 : 1. Без `oklch(from …)` окна прозрачные.
- **Клавиатура и скринридер.** Фокус в навигации не виден; нижний лист и справка не модальны; «Показать
  пароль» недоступно; «×» окон без имени, подписи PrimeNG и FullCalendar по-английски; секции без
  заголовков; ошибки полей только рамкой; snackbar забирает фокус и исчезает через 3 с; поля фильтров без
  подписей; ссылки в тексте — только цветом; при шрифте 200 % — горизонтальная прокрутка.

Новые решения: ADR-0023 (цвет статусов, роль warning, контраст цвета портала), ADR-0024 (доступность:
фокус, заголовки секций, ссылки, snackbar, ошибки полей, крупный шрифт), ADR-0025 (состояния страницы:
загрузка, ошибка, пусто); уточняют ADR-0015, ADR-0017, ADR-0018 и ADR-0019.

## Этап 72. Сорванные сценарии

- [x] 72.1 **F** Окна внутри раскрываемых секций — по центру экрана с затемнением на весь экран: раскрытие
      секции без заливающей анимации `transform`, окна секций — `appendTo="body"`; E2E «окно в раскрытой
      секции».
- [x] 72.2 **F** Состояние страницы «загрузка — ошибка — готово»: `tb-loading` (индикатор M3E) и
      `tb-load-error` с «Повторить» в `shared/ui`; пустое состояние — только после загрузки; одинаковый
      тост ошибки — один раз.
- [x] 72.3 **F** Телефон 360 px: адрес встречи в уведомлениях переносится, выпадающие списки не шире
      экрана, правка цены — поле во всю ширину под подписью.

## Этап 73. Цвет и контраст

- [x] 73.1 **F** Роли warning и info в пресете; статусы, `p-message`, теги, бейджи, события календаря и
      код подключения — через роли M3 с контрастом ≥ 4,5 : 1 в обеих темах при любом цвете портала.
- [x] 73.2 **F** Красный текст — тон error с контрастом 4,5 : 1; приглушённый текст — on-surface-variant
      без прозрачности.
- [x] 73.3 **F** Primary готовых палитр и своего цвета — тон с контрастом 4,5 : 1; тоны ролей считаются
      при смене цвета портала (без `oklch(from …)` в браузере); проверка своего цвета — все пары ролей в
      обеих темах, порог 4,5 : 1, близость к success и error.

## Этап 74. Клавиатура и скринридер

- [x] 74.1 **F** Кольцо фокуса 3 px в rail, нижней панели, на активном разделе и на filled-кнопках;
      навигация и меню с `aria-current`, `aria-expanded`, `aria-haspopup`; видимое имя меню пользователя
      входит в доступное.
- [x] 74.2 **F** Нижний лист занятия и панель справки — модальные, с удержанием фокуса; после закрытия
      окна фокус возвращается на кнопку, открывшую его; после ошибки входа — в поле пароля.
- [x] 74.3 **F** Заголовки секций — `h2` в `tb-card-title` и `tb-fold-card`; русские подписи PrimeNG
      (`translation`) и FullCalendar (`locale`); имя «Закрыть» у «×» окон и листов; «Показать пароль» —
      кнопка 40×40 с именем.
- [x] 74.4 **F** Ошибки полей — текстом под полем, `aria-invalid` и `aria-describedby`; обязательные поля
      отмечены; у неактивной кнопки отправки — причина; видимые подписи у фильтров журнала, цены, цвета,
      «с / до».
- [x] 74.5 **F** Snackbar: без захвата фокуса, `role="status"` для успеха, 5 с (ошибка — 8 с), над FAB,
      без повторов; ссылки внутри текста подчёркнуты.
- [x] 74.6 **F** Шрифт 200 % и масштаб 400 %: каркас и границы окон в `em`, одна система медиазапросов без
      щелей 768–769 и 1199–1200, без горизонтальной прокрутки.
