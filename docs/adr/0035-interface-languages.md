# ADR-0035. Языки интерфейса

- Статус: принято
- Дата: 2026-10-11
- Действующие правила: [docs/design-system.md](../design-system.md), раздел «Тексты и языки»

## Контекст

До 0.11 все тексты веб-интерфейса были написаны по-русски прямо в шаблонах и коде компонентов. Учитель хочет
английский интерфейс (ученики и коллеги, не читающие по-русски) и возможность позже добавить другие языки без
переписывания компонентов.

Варианты:

- `@angular/localize` — перевод при сборке: отдельная сборка на каждый язык, переключение — другой адрес.
  Не подходит: портал ставят одним готовым образом (ADR-0032), язык выбирает сам пользователь.
- `ngx-translate` / Transloco — словари JSON и ключи-строки: опечатку в ключе и забытый перевод видно только
  в работающем приложении.
- Свои словари на TypeScript — выбраны.

## Решение

- **Реестр языков** — `core/i18n/language.ts` (`LANGUAGES`: код, своё название, локаль чисел и дат). Сейчас
  `ru` (исходный) и `en`. Выбор хранится на устройстве (`tb.language`, как тема, ADR-0015); без выбора —
  русский.
- **Язык выбирается один раз при загрузке страницы**; смена языка перезагружает страницу. Поэтому подписи,
  вычисленные при загрузке модуля (карты статусов, пункты меню), не нужно делать реактивными, а `LOCALE_ID`
  Angular, переводы PrimeNG, локаль FullCalendar и Excalidraw задаются при старте.
- **Словари** лежат рядом с кодом: `core/i18n/{ru,en}.ts` (рамка: навигация, заголовки, ошибки сервера),
  `shared/i18n/{ru,en}.ts` (общие слова: «Отмена», «Сохранить»…) и `features/<m>/i18n/{ru,en}.ts` — по одному
  на модуль (границы модулей не нарушаются). `texts.ts` рядом выбирает словарь текущего языка:
  `translations({ ru, en })`. Русский словарь — исходный; тип `Translation<typeof ru>` требует в переводе те же
  ключи, строки для строк и функции с теми же параметрами для текстов с числами и именами. Пропущенный ключ —
  ошибка компиляции.
- Компонент берёт тексты из словаря (`protected readonly t = T.studentsPage`) и в шаблоне пишет
  `{{ t.title }}`, `[label]="t.add"`; склонения — функции словаря (`countOf` по правилам языка).
- **Переключатель** — в меню пользователя под темой (названия языков — на своём языке), на страницах входа и
  приглашения — строка языков под карточкой.
- **Новый язык:** строка в `LANGUAGES`, файл `xx.ts` рядом с каждым `ru.ts` (компилятор назовёт все словари,
  где его нет), переводы PrimeNG в `app.config.ts`, локали FullCalendar и Excalidraw, справка
  `features/help/articles/*.xx.ts`.
- Тест `expectComplete` (`@testing/i18n`) каждого словаря проверяет ключи и вызывает все функции перевода.

## Последствия

- Тексты, которые формирует сервер, остаются русскими: уведомления во «Входящих», сообщения ботов, описания
  настроек администратора, письма календаря. Их перевод — отдельная задача (язык пользователя на сервере);
  решена в 0.11.1 — [ADR-0036](0036-server-texts-in-the-users-language.md).
- Тесты компонентов по-прежнему проверяют русские тексты (язык по умолчанию); английский проверяют
  `expectComplete` и E2E.
- Глоссарий (`docs/glossary.md`) ведёт и английские слова понятий.
