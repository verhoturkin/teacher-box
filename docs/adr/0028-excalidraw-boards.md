# ADR-0028. Доски Excalidraw

- Статус: принято
- Дата: 2026-10-05
- Заменяет: [ADR-0012](0012-meetings-and-boards.md) в части досок (модуль `boards`)
- Действующие правила: [docs/modules/boards.md](../modules/boards.md)

## Контекст

С 1.4 доска — это ссылка на Холст у одного ученика или одной группы (ADR-0012). Серверного API досок у Холста
нет, поэтому интеграция свелась к ссылкам и буферу обмена, а модель «одна доска — один владелец» не даёт вести
одну доску с несколькими учениками и группами. Учителю нужна своя доска внутри портала: открыть с урока,
порисовать вместе с учеником, вернуться в меню, не потерять работу.

Excalidraw (MIT) — готовый редактор досок в виде npm-пакета `@excalidraw/excalidraw` (0.18, ESM). Это компонент
React, а портал написан на Angular 21 (zoneless, signals). Начальный бандл портала не должен вырасти: React и
Excalidraw нужны только на странице доски.

## Решение

### Модель

- **Два вида досок:** `EXCALIDRAW` — своя доска портала, `LINK` — внешняя доска по ссылке (Холст или любая другая
  https-доска): название и ссылка, ничего больше. Упоминания API Холста уходят.
- **Участники — многие ко многим:** доска привязывается к любому числу учеников и групп (`board_members`).
  Ученик видит доску, если он участник напрямую или через текущую группу; ушёл из группы — доступа нет. Ученик
  всегда может редактировать (режима «только чтение» нет). Остальным — 404.
- Старые доски-ссылки с одним владельцем не переносятся: миграция их удаляет (учитель создаёт заново за минуту).

### Хранение

- **Сцена** — в схеме `boards` (`board_scenes`: элементы и белый список `appState` в JSON, `scene_version`).
  Размер сцены ограничен.
- **Картинки** — в `FileStorage`, пространство `boards/<boardId>/`, по `fileId` Excalidraw; только png, jpeg,
  webp, gif (без SVG); файл хранится, пока на него ссылается сцена или любая копия.
- **Резервные копии доски:** ежедневная копия каждой изменённой доски (cron и число хранимых копий — настройки
  `TEACHERBOX_BOARDS_BACKUP_*`) и ручные копии учителя с ограничением на доску. Восстановление сначала сохраняет
  текущую сцену как копию. Копии и картинки входят в общую резервную копию портала.

### Совместная работа — опрос, без реального времени

- Сохранение: `PUT /api/boards/{id}/scene` с `baseVersion`; сервер сливает изменения по `id` элемента
  (`version`, затем `versionNonce` — как `reconcileElements` в Excalidraw), удалённые элементы остаются
  «надгробиями» (`isDeleted`), чтобы удаление не воскресало. Ответ — слитая сцена и новая версия.
- Пока вкладка видна, редактор раз в ~5 с спрашивает `GET …/scene?since=<версия>` (204 — без изменений) и
  применяет чужие изменения через `reconcileElements`, не сбивая выделение и рисование.
- WebSocket, курсоры и присутствие не делаем: опроса хватает для урока «учитель + ученик», а реальное время
  требует отдельного канала через прокси и nginx. Перенесено в Backlog.

### Встраивание — «остров» React через динамический `import()`

- React и Excalidraw импортирует только `features/boards/editor/excalidraw-island.ts` (статически: esbuild
  отдаёт динамическому `import()` CommonJS-модуля React лишь `default`), а `excalidraw-loader.ts` — единственное
  место с динамическим `import()` этого файла; `excalidraw-host.ts` вызывает `createRoot` и
  `root.render(createElement(Excalidraw, props))` без JSX (tsconfig не меняется) и размонтирует корень при
  уничтожении компонента. ESLint разрешает импорт `react*` и `@excalidraw/*` только в
  `features/boards/editor/**`.
- Стили Excalidraw — отдельный невстраиваемый бандл стилей (`inject: false`), загрузчик подключает его через
  `<link>`. Шрифты копируются в `excalidraw-assets/` и задаются через `window.EXCALIDRAW_ASSET_PATH` — без CDN
  (портал работает и без внешнего интернета, CSP не расширяется на чужие домены). Excalidraw всегда дописывает
  к источникам шрифта свой CDN (`esm.sh`), и Chrome сообщает о нарушении CSP уже при создании `FontFace` — сотни
  ошибок в консоли на одну доску без единого запроса. Поэтому загрузчик оборачивает `FontFace` и убирает из
  списка источников только этот CDN (`self-hosted-fonts.ts`).
- **CSP не меняется.** Проверено в контейнере single и split: редактор, шрифты, экспорт PNG и SVG работают при
  `script-src 'self'`. Вырезание глифов при экспорте в SVG (wasm + worker) использует embind с `new Function` —
  это потребовало бы `'unsafe-eval'` для всего портала, поэтому Excalidraw пропускает его сам и встраивает
  шрифт целиком (SVG немного больше, в консоли сообщение при экспорте). `'wasm-unsafe-eval'` и `worker-src` не
  нужны.
- Angular-компонент `board-canvas` (входы `scene`, `theme`, выход `sceneChange`, состояния загрузки и ошибки по
  ADR-0025) — граница острова; тесты подменяют загрузчик, React в jsdom не запускается.

Отвергнутые варианты:

- **Веб-компонент, собранный Vite отдельно.** Второй сборщик и второй `package.json` в репозитории, отдельная
  проверка версий и лицензий, свой путь в Docker; выигрыша по размеру нет — React всё равно грузится целиком.
- **Отдельное мини-приложение в `iframe`.** Изоляция хорошая, но тема, язык, авторизация, автосохранение и
  кнопка «назад» идут через `postMessage`; ещё одна точка входа в nginx и CSP (`frame-src`), двойная загрузка
  на телефоне.
- **Библиотеки-обёртки Angular↔React** (`ngx-react` и подобные). Мало пользователей, отстают от версий Angular
  (zoneless, 21), добавляют зависимость ради десятка строк `createRoot`/`render`.

## Последствия

- В проекте появляются React 19 и Excalidraw (оба MIT); их обновления проверяются так же, как Angular и PrimeNG.
  React и Excalidraw приходят ленивыми чанками только на странице доски; начальный бандл растёт лишь на общие
  хелперы `tslib` и списки экспортов чанков (замер ниже).
- Опрос раз в 5 с даёт задержку до нескольких секунд: одновременное рисование одной фигуры двумя людьми решается
  по версии элемента (последняя правка побеждает целиком).
- Резервные копии досок увеличивают объём данных; хранение ограничено настройкой числа ежедневных копий и
  лимитом ручных копий.
- Доски-ссылки прежнего вида удаляются при обновлении до 1.7.0 — это отмечается в CHANGELOG.
- Размеры ленивых чанков (замер при сборке 1.7.0) — ниже.

### Замер бандла

Сборка `production`, Excalidraw 0.18.1, React 19.3 (2026-10-05):

| Что | Размер | gzip |
|---|---|---|
| Начальный бандл до Excalidraw | 726,58 КБ | 161,68 КБ |
| Начальный бандл, когда маршрут ведёт к редактору (React и Excalidraw в нём нет; +`tslib`, экспорты чанков) | 729,80 КБ | 164,66 КБ |
| JS острова при открытии доски (загрузчик, React, ReactDOM, Excalidraw — 11 ленивых чанков) | 1355 КиБ | 441 КиБ |
| `excalidraw.css` (невстраиваемый бандл, `no-cache` — имя без хеша) | 142 КиБ | 22 КиБ |
| Шрифты `excalidraw-assets/fonts/` (качаются по одному при отрисовке текста; Xiaolai — только для CJK) | 14 МБ на диске | — |

Mermaid, KaTeX и переводы Excalidraw — отдельные ленивые чанки, грузятся только при использовании (диалог
«Текст в диаграмму», формулы, другой язык). Бюджет `initial` не меняется; замер повторяется, когда в 1.7.0
появятся настоящие маршруты редактора.
