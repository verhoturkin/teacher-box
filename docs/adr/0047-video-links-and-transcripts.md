# ADR-0047. Видео в задании — по ссылке, ИИ читает расшифровку

- Статус: принято
- Дата: 2026-10-19
- Дополняет: [ADR-0039](0039-ai-reads-homework-sources.md), [ADR-0042](0042-ai-reads-picked-files.md)

## Контекст

Учитель строит задание вокруг ролика: «посмотрите видео и ответьте». Ролики почти всегда уже лежат на YouTube,
реже на Rutube и в VK Видео. Хранить видеофайлы на сервере репетитора дорого (сотни мегабайт, отдача по частям,
лимиты nginx), а учитель этого не просит. ИИ-помощник должен опираться на ролик, но основной провайдер учителя —
DeepSeek: он читает только текст, ни кадры, ни звук ему не передать. Кадры из чужого плеера браузер не вырежет.

## Решение

1. **Только ссылки.** В задании до 5 видео: ссылка (http / https), название, расшифровка и флаг «Показывать
   ученику». `VideoLink.parse` узнаёт YouTube (`watch`, `youtu.be`, `shorts`, `embed`, `live`, `t=`), Rutube
   (`/video/<id>`, `/play/embed/<id>`) и VK Видео (`video-<oid>_<id>` на `vk.com` / `vkvideo.ru`); у них ученик
   смотрит встроенный плеер (`youtube-nocookie.com`, `rutube.ru/play/embed`, `vkvideo.ru/video_ext.php`), любая
   другая ссылка открывается в новой вкладке. CSP получает `frame-src` только этих трёх адресов.
2. **Видео — часть задания.** Список приходит в тех же запросах создания и изменения (заменяется целиком), его можно
   менять и у сохранённого задания; таблица `homework.assignment_videos` удаляется вместе с заданием.
3. **Расшифровка — текст с метками времени** `[m:ss]`, до 100 000 символов. Источники: вручную; файл .srt / .vtt
   (разбирает браузер); «Взять субтитры с YouTube» — сервер (`homework/youtube/YoutubeCaptions`) спрашивает
   у YouTube данные плеера (InnerTube, клиент `ANDROID`), выбирает дорожку (ручные субтитры на языке речи, иначе
   дорожку по умолчанию, иначе автоматические) и склеивает её в абзацы по ~30 секунд. Прокси —
   `TEACHERBOX_HOMEWORK_YOUTUBE_PROXY` (из России YouTube замедлен).
4. **ИИ читает расшифровку.** Источник черновика `{type: VIDEO, title, url, transcript}` приходит из фронтенда
   целиком — как файлы нового задания в ADR-0042, и для нового, и для сохранённого задания. `LlmSource` с типом
   `text/plain`: Anthropic — текстовый документ с названием, OpenAI-совместимые API — текстовая часть сообщения.
   Считается среди 5 источников. Ученик видит расшифровку, только если учитель включил флаг.

## Последствия

- Видео без расшифровки ИИ знает только по названию и ссылке.
- Субтитры YouTube берутся неофициальным путём: официальный API отдаёт их только владельцу ролика. YouTube может
  изменить этот путь или потребовать подтверждения «вы не бот» — тогда кнопка сообщает об ошибке, а расшифровку
  можно вставить вручную или загрузить файлом. Расшифровка сохраняется в задании, поэтому YouTube спрашивают один
  раз, а не при каждом запросе к ИИ.
- Ролик могут удалить или закрыть с площадки: портал не хранит копию, у ученика останется пустой плеер.
