# ADR-0046. Material Symbols Rounded вместо primeicons

- Статус: принято
- Дата: 2026-10-14
- Уточняет: [ADR-0019](0019-material-3-expressive.md), [ADR-0044](0044-m3-expressive-alignment-2026-10.md)
- Действующие правила: [docs/design-system.md](../design-system.md) §1 «Icons» — сводка решений; при расхождении верна она

## Контекст

Интерфейс построен на M3 Expressive, а значки были из `primeicons` 7: тонкие контурные глифы другого рисунка,
без заливки, без перечёркнутых вариантов (микрофон и камера зачёркивались линией в CSS), без значка доски
(маска Tabler в `styles.scss`). M3 выделяет активный раздел навигации **залитым** значком, а значки кнопок
задаёт размером 20 / 24 dp — у шрифта без осей этого нет. `primeicons` 8 — под коммерческой лицензией PrimeUI
(ADR-0007), обновлять его нельзя.

Material Symbols (Apache-2.0) — родной набор M3: вариативный шрифт с осями заливки (FILL), насыщенности (wght),
градации (GRAD) и оптического размера (opsz). Полный шрифт Rounded из npm-пакета `material-symbols` весит
**5,4 МБ** — для телефона на 4G это десятки секунд первой загрузки, а с `font-display: block` значки всё это время
невидимы.

## Решение

1. **Material Symbols Rounded**, свой хостинг (без CDN; CSP `font-src 'self'` уже это разрешает).
2. **Подмножество шрифта из используемых значков.** Скрипт `npm run icons` (`frontend/scripts/icons.mjs`) находит в
   `src/` классы `tb-i-<имя>`, берёт эти глифы из полного шрифта (`subset-font`, HarfBuzz) и закрепляет оси:
   wght 400, opsz 20–24, GRAD −25…0, FILL 0–1. Результат — `core/theme/symbols.woff2` и карта
   `core/theme/icons.scss` (имя → кодовая точка) — хранится в репозитории; тест правил дизайна падает, если
   карта и классы расходятся. Пакеты `material-symbols`, `subset-font`, `fontkit` — только devDependencies.
   Замер на 95 значках: **29 КБ** (полный шрифт — 5,4 МБ; все оси без закрепления — 108 КБ). На профиле
   «медленный 4G» Lighthouse (1,6 Мбит/с) это ≈ 0,15 с против ≈ 27 с.
3. **Кодовые точки, а не лигатуры.** Значок — `::before { content: '\e88a' / '' }`. В подмножестве нет букв,
   поэтому лигатуры не нужны: пока шрифт грузится, на месте значка пусто, а не слово `home`; пустой
   альтернативный текст не даёт экранным дикторам читать символ из частной области Unicode. Классы
   (`p-button [icon]` принимает только классы) — `tb-i tb-i-<имя>`, имя = имя символа.
4. **Размеры** (M3): 24 px — списки, навигация, кнопки-значки; 20 px — кнопки с подписью (M3E small);
   18 px — чипы. Залитый значок — у активного раздела навигации и отмеченных состояний.
   Тёмная тема — GRAD −25 только для значков.
5. **Один смысл — один символ**: таблица в design-system §1 «Icons». Видимые значки PrimeNG (стрелка списка,
   «×» диалога, календарь и т. п.) заменяются этим же набором; `primeicons` удаляется.

## Последствия

- Новый значок: написать класс `tb-i-<имя>` и запустить `npm run icons` (оба файла — в тот же коммит).
- Перечёркнутые микрофон и камера — символы `mic_off`, `videocam_off`; CSS-линия больше не нужна.
- Логотипов брендов (Telegram, Google) в наборе нет: Telegram — `send`, «Подключить Google» — `link`.
- Обновление пакета `material-symbols` меняет только рисунок значков; кодовые точки стабильны.
