# ADR-0039. ИИ читает источники заданий: страницы учебников и файлы задания

- Статус: принято
- Дата: 2026-10-12
- Дополняет: [ADR-0006](0006-ai-integration.md), [ADR-0033](0033-textbooks.md)
- Дополнено: [ADR-0042](0042-ai-reads-picked-files.md) — файлы нового задания идут с запросом

## Контекст

С 0.14.0 учитель просит ИИ составить задание «по страницам 12–14 учебника» или «по этому файлу». До сих пор
модуль `ai` зависел только от `shared`: тексты присылал фронтенд (ADR-0006). Страницы учебника — это PDF или
картинка до 100 МБ, файлы задания — до лимита `homework`; гонять их через браузер дважды (скачать, потом
загрузить в `ai`) медленно и бессмысленно — сервер и так держит их у себя.

Ограничения:

- Изоляция модулей (AGENTS.md §4.2): чужие данные — только через `api`-фасады, без циклов. `homework` уже
  зависит от `textbooks::api`; от `ai` не зависит ни один модуль.
- Провайдеры: Anthropic принимает PDF блоком `document` и картинки блоком `image`; OpenAI-совместимые API (и
  Gemini через них) надёжно принимают только картинки (`image_url` с `data:`).
- Размер запроса: у Anthropic до 32 МБ и 600 страниц; длинные PDF дороги по токенам.

## Решение

1. **Зависимости.** `ai` может зависеть от `textbooks::api` и `homework::api` (только чтение). `homework::api`
   получает фасад `AssignmentFiles.file(assignmentId, attachmentId)` — файл задания (имя, тип, содержимое);
   чужой файл — 404.
2. **Запрос.** Фронтенд присылает в черновик не файлы, а ссылки на них: `sources` — до 5 штук, учебник
   (`textbookId`, `pages`) или файл задания (`assignmentId`, `attachmentId`). Только учитель, как и весь
   `/api/teacher/ai/**`.
3. **Что берётся.** Учебник — `Textbooks.content`: PDF, вырезанный по страницам, или картинка; страниц не
   больше 20 (пустые страницы у PDF — весь учебник, если в нём не больше 20 страниц); файл Word —
   `ai.source-unsupported`. Файл задания — PDF или картинка (png, jpeg, webp, gif), иначе
   `ai.source-unsupported`. Всего не больше 20 МБ — иначе `ai.source-too-large`.
4. **Провайдеры.** `LlmRequest.sources` — имя, тип, байты. Anthropic: PDF — блок `document` (с именем как
   заголовком), картинка — `image`, перед текстом запроса. OpenAI-совместимые: картинка — `image_url`, PDF
   модуль `ai` сам рисует постранично (PDFBox, 100 dpi) в PNG.
5. **Журнал.** В `ai.requests` по-прежнему только метаданные: ни содержимое, ни имена файлов не сохраняются.

## Последствия

- Новый файл задания можно отдать ИИ, только когда он сохранён в задании; страницы учебника — сразу после
  выбора (они уже на сервере).
- `ai` перестаёт быть полностью независимым: его тесты подменяют фасады `Textbooks` и `AssignmentFiles`.
- Запросы с источниками заметно дороже по токенам — их видно на странице «ИИ» в общем расходе.
