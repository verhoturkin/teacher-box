# ADR-0042. ИИ читает файлы нового задания, ещё не сохранённые

- Статус: принято
- Дата: 2026-10-13
- Дополняет: [ADR-0039](0039-ai-reads-homework-sources.md)

## Контекст

По ADR-0039 фронтенд называет источники черновика ссылками: учебник или файл задания. Файлы нового задания
загружаются на сервер только при «Выдать» — после того как ИИ составил текст. Поэтому в окне выдачи учитель мог
опереться на учебники, но не на свои материалы (скан страницы, PDF с задачами) — а именно так задание обычно и
начинается.

## Решение

1. `POST /api/teacher/ai/homework-draft` принимает ещё и `multipart/form-data`: часть `brief` — тот же JSON
   (`prompt`, `title`, `sources`), части `files` — выбранные файлы. JSON-вариант не меняется.
2. Файлы из запроса — источник `DraftSources.Upload` с теми же правилами: PDF или картинка (png, jpeg, webp, gif),
   иначе `ai.source-unsupported`; вместе со ссылками — не больше 5 источников и 20 МБ (`ai.source-too-large`).
3. Файлы нигде не сохраняются: модуль `ai` читает их из запроса и отдаёт провайдеру; в `ai.requests` — по-прежнему
   только метаданные.
4. Фронтенд отправляет multipart, только когда выбраны несохранённые файлы; файлы сохранённого задания идут
   ссылками, как раньше.

## Последствия

- Выбранный файл уходит на сервер дважды — для черновика и при выдаче задания. Он не больше 20 МБ, а черновик
  просят не каждый раз, поэтому это дешевле, чем хранить черновые файлы.
- Ограничение ADR-0039 «новый файл можно отдать ИИ, только когда он сохранён» снято.
