# ADR-0007. Frontend: Angular 21 LTS + PrimeNG 21 (MIT)

- Статус: принято
- Дата: 2026-09-25

## Контекст

Требование: Angular + PrimeNG «последних LTS или просто стабильных версий».
На дату решения:

| Пакет | Последняя | LTS/стабильная линия |
|---|---|---|
| Angular | 22.2 (active) | 21.2.x (LTS) |
| PrimeNG | 22.1 | 21.1.x (для Angular 21) |

Начиная с **PrimeNG 22** (и `@primeuix/themes` 3, `primeicons` 8) библиотеки распространяются
под коммерческой **PrimeUI License**: бесплатно только по Community License (лимиты по выручке и
числу разработчиков, ежегодное подтверждение), обязателен лицензионный ключ, без ключа
показывается лицензионное уведомление; запрещено извлечение исходников. Линия **PrimeNG 21.x —
MIT** (как и `@primeuix/themes` 2.x, `primeicons` 7).

## Решение

- **Angular 21.2 LTS**, **PrimeNG 21.1 (MIT)**, `@primeuix/themes` 2.x, `primeicons` 7, TypeScript 5.9.
- Для self-hosted продукта это исключает лицензионные ключи, ограничения и уведомления в UI,
  и соответствует требованию «последняя LTS».
- Установка зависимостей — **npm ≥ 11** (в npm 10.9 баг arborist `Cannot read properties of null
  (reading 'edgesOut')` при разрешении optional peer-зависимостей vitest). Локально без обновления
  глобального npm: `npx -y npm@11 ci`.

## Последствия

- (+) Полностью открытый стек, никаких лицензионных проверок в рантайме.
- (−) Angular 21 LTS поддерживается до ~мая 2027. Переход на Angular 22+ потребует либо
  Community/Commercial-ключа PrimeUI, либо смены UI-библиотеки — решение принимается отдельным ADR
  до окончания LTS.
