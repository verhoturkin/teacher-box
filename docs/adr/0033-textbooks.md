# ADR-0033. Учебники

- Статус: принято
- Дата: 2026-10-07
- Действующие правила: [docs/modules/textbooks.md](../modules/textbooks.md)

## Контекст

Учительница ведёт уроки по учебникам и рабочим тетрадям: PDF, сканы страниц, документы Word. До 0.10.0 их
приходилось прикладывать к каждому заданию заново, а на доску — переснимать страницы вручную. Нужно одно место
для учебников с доступом ученикам и группам, ссылки на страницы учебника из задания и вставка страниц на доску.

## Решение

### Модуль `textbooks`

- Новый бизнес-модуль `textbooks` (схема `textbooks`), зависит от `shared` и `identity::api`. Учебник — запись
  с видом (`TEXTBOOK` «Учебник», `WORKBOOK` «Рабочая тетрадь», `OTHER` «Другое»), названием, курсом (свободный
  текст), числом страниц и **одним файлом**. Файл можно заменить, учебник — удалить вместе с файлом.
- Файлы: картинки (png, jpeg, webp, gif), PDF, DOC, DOCX; тип проверяется по первым байтам, SVG не принимается.
  До 100 МБ (лимит multipart бэкенда и `client_max_body_size` nginx для `/api/teacher/textbooks` подняты).
- Число страниц: у PDF — из файла, у картинки — 1, у DOC/DOCX — вводит учительница (может не указать).
- Доступ: учитель — ко всем; ученик — к учебникам, где он участник сам или через текущую группу (как у досок,
  ADR-0028); остальным — 404. Администратор — нет.

### Страницы рендерит сервер (PDFBox)

- Apache PDFBox 3 (Apache 2.0): число страниц, вырезка страниц в новый PDF, картинка страницы
  (`GET /api/teacher/textbooks/{id}/pages/{n}` — PNG ~150 dpi, не шире 2000 px). Картинка-учебник отдаётся
  как есть. DOC/DOCX не рендерятся — для них нет ни вырезки, ни вставки на доску (понадобился бы LibreOffice).
- Отвергнуто: **pdf.js в браузере** — ещё ~1 МБ скриптов и воркер в бандле, отдельная вырезка страниц для
  ученика всё равно нужна на сервере; **хранить картинки страниц заранее** — место на диске ради редкой операции.

### Привязка к заданию — в `homework`

- `homework` зависит от `textbooks::api` (фасад `Textbooks`: сводки учебников, содержимое по страницам —
  только чтение). Привязка «задание → учебник + страницы» (`1-3, 7`) хранится в `homework`; страницы
  проверяются по числу страниц учебника.
- Ученик с заданием получает **только привязанные страницы** (`GET /api/me/homework/tasks/{taskId}/textbooks/{id}`):
  PDF вырезается сервером, остальные файлы отдаются целиком. Доступ проверяет `homework` (задание ученика),
  `textbooks` про задания не знает. Удалённый учебник пропадает из заданий.

### На доску — фрейм с картинками страниц

- «На доску» (только доски Excalidraw): редактор доски получает список адресов картинок страниц (передача через
  `localStorage`, как у материалов 0.7), загружает их, кладёт картинками в ряд и обводит фреймом с названием
  учебника и номерами страниц. `boards` не знает об учебниках — только адреса картинок.

## Последствия

- Новая зависимость PDFBox (~3 МБ), рендер в headless AWT; образ `eclipse-temurin` alpine уже содержит
  fontconfig и шрифты.
- Учебники и их файлы входят в резервную копию портала и в полный сброс.
- Таблица зависимостей модулей (AGENTS.md §4.2): `textbooks` — `shared`, `identity::api`; `homework` +
  `textbooks::api`.
