# ADR-0065: CSS PrimeNG в слое `primeng`

Статус: принято. Пункт плана: 400.1.

## Контекст

PrimeNG вставляет CSS темы и компонентов в `<head>` во время работы. Без слоёв наши правила
спорили с ним специфичностью и порядком: глобальные стили брали `!important`, стили компонентов —
`:host ::ng-deep`, хотя элемент с нашим классом часто лежит в нашем же шаблоне (в PrimeNG 21
`styleClass` попадает на хост компонента: `p-tag`, `p-progressbar`, `p-message`, `p-card`,
`p-table`).

## Решение

`providePrimeNG` включает `cssLayer: { name: 'primeng', order: 'base, primeng' }`: весь CSS
PrimeNG (переменные пресета, стили компонентов) — в `@layer primeng`. Порядок слоёв задают и
`cssLayer.order` (стиль PrimeNG стоит в `<head>` раньше `styles.css` и объявляет порядок первым),
и `styles/_layers.scss` — первый партиал `styles.scss`.

- `@layer base` — умолчания элементов, которые компоненты PrimeNG переопределяют: правило `a`
  (цвет ссылки, подчёркивание, кольцо фокуса). Без слоя оно перекрасило бы `a pButton`.
- Остальные глобальные стили и стили компонентов — вне слоёв и побеждают PrimeNG при любой
  специфичности: против его селекторов не нужны `!important` и повышение специфичности.
- `::ng-deep` — только для DOM чужого шаблона: внутренности компонента PrimeNG (`.p-button`
  внутри `p-button`, `.p-card-body`, `.p-select-label`, `.p-datatable-tbody`), разметка
  дочернего компонента, проекция в `ng-content`, HTML Markdown. Класс на хосте в своём шаблоне
  пишется без `::ng-deep`.
- `!important` остаётся против inline-стилей PrimeNG (маска диалога, положение тоста), против CSS
  вне слоя (FullCalendar), для «уменьшения движения» и скрытия кольца фокуса без клавиатуры.

## Последствия

Убраны 19 `::ng-deep` (осталось 19, все — в чужой DOM) и 3 `!important` (фон маски экранного
диалога, ширина полноэкранного и экранного диалога). Снимки всей галереи (две ширины, обе темы) до
и после совпадают попиксельно; геометрия открытых диалогов и снекбара та же.

Слой вскрыл мёртвое правило `.p-button { font-size: 0.875rem }`: PrimeNG перебивал его своим
`1rem`, и кнопки показывают 16 px, а не Label Large (14 px). Размер оставлен как есть: из правила
убран только `font-size`, его `line-height` и `letter-spacing` действовали и остались; перейти на
14 px — отдельное видимое изменение. Решено 2026-11-16: кнопки переведены на Label Large 14 px
правилом `.p-button:not(.p-button-sm, .p-button-lg)` в `css` кнопки пресета; подписи уже на
4–10 %, высота 40 px не меняется.

Новый CSS сторонней библиотеки вне слоя снова спорит специфичностью: такой пакет кладём в свой
слой.
