# ADR-0056: Настройки учителя — в портале, не в .env

Дата: 2026-11-09. Статус: принято. Дополняет ADR-0014 и ADR-0016.

## Контекст

Почти всё, что учитель настраивает под себя — часовой пояс, валюту, длительность занятия,
напоминания, ботов мессенджеров, Google, ИИ, — задаётся переменными `.env`. Учитель редко
работает с сервером: чтобы поменять напоминание, ему нужен администратор, правка файла и
перезапуск. Настройки администратора (ADR-0016) тоже применяются только после перезапуска, хотя
большинству из них он не нужен.

## Решение

- У каждой настройки каталога (`SettingDefinition`) есть владелец `owner`:
  - `TEACHER` — настройка учителя. Хранится строкой в схеме модуля-владельца, меняется в
    «Настройках» и в мастере первого запуска и действует сразу. `.env` (и файл настроек
    администратора) читается для неё один раз — при первом запуске новой версии, чтобы перенести
    прежнее значение, — и больше никогда. Её нет в `.env.example` и в настройках администратора:
    там остаётся только список «Перенесено в настройки учителя» с переменными, которые ещё заданы
    (без значений — это данные учителя);
  - `ADMIN` — настройка администратора: порядок `.env` > интерфейс > умолчание прежний;
  - `ENV_ONLY` — только `.env`: Docker Compose, учётные записи, восстановление доступа.
- Настройка администратора с пометкой `live` применяется без перезапуска: сохранённое значение
  сразу заменяется в источнике свойств `teacherboxAdminSettings`, публикуется событие
  `shared.settings.SettingsChanged(names)`. Её потребители читают значение при каждом
  использовании (`shared.settings.LiveProperties` связывает их `@ConfigurationProperties` заново)
  или пересобирают построенное из неё (клиент, расписание задач) по событию. Перезапуск нужен только
  для остальных настроек.

## Последствия

- Учитель меняет свои настройки сам и сразу; администратор видит, какие старые переменные можно
  удалить из `.env`.
- Каждый модуль получает свою таблицу настроек и фасад для переноса старого значения; перенос и
  перевод потребителей идут по этапам 363.2–363.6 плана.
- Значение настройки учителя попадает в резервные копии вместе со схемой модуля; ключи API
  хранятся так же, как токены мессенджеров, без шифрования.
