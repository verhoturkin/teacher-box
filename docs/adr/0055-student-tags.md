# ADR-0055: Теги учеников

Дата: 2026-11-03. Статус: принято.

## Контекст

Учитель хочет отмечать учеников короткими признаками — «Уровень английского» A1–C2, «Класс»
1–11, «Цель» — и чтобы ИИ учитывал их в черновиках заданий, тестов и проверок, не набирая их
каждый раз в запросе. Признаки — рабочие заметки учителя: ученик, боты и администратор их не
видят. Модуль `ai` сейчас зависит только от `shared`, `textbooks::api` и `homework::api`
(ADR-0039) и об учениках ничего не знает.

## Решение

- Теги живут в `identity`, рядом с учениками и группами: таблицы `tags` (название 1–60, флаг
  «Учитывать в ИИ», порядок, `version`), `tag_values` (упорядоченные значения 1–40) и
  `student_tags` (у ученика не больше одного значения каждого тега).
- Теги — данные только учителя: `/api/teacher/tags` и (этап 362.2) карточка ученика у учителя.
  Их нет в `/api/me`, в ответах администратора, в ботах и в `identity::api` — другие модули о
  тегах не знают.
- Тег бывает двух видов (`tags.kind`): `LIST` — список значений, `TEXT` — свободный текст ученика
  («Интересы: футбол», «Цель: ЕГЭ») длиной 1–120 в `student_tags.text`; у строки `student_tags`
  задано ровно одно из `value_id` и `text`. Вид тега, уже выставленного ученикам, не меняется
  (409). Форма `PUT /api/teacher/students/{id}/tags` не изменилась: для `TEXT` строка — это
  текст, для `LIST` — id значения. Фильтр списка `?tag=` работает только по значениям списков.
- Правка тега идёт с оптимистической блокировкой; удалённое значение снимается с учеников, и
  ответ говорит, со скольких. Удаление тега снимает его со всех.
- `ai` не получает зависимости от `identity`. Фронтенд сам собирает теги «Учитывать в ИИ» у
  получателей и отправляет их с каждым запросом черновика как контекст — так же, как сводку
  занятия. В промпте контекст — данные и умолчания: явный запрос учителя важнее. Контекст не
  сохраняется в `ai.requests`.

## Последствия

- Граф зависимостей модулей не меняется; ИИ видит только то, что учитель видит на экране
  черновика и может снять для одного запроса.
- Значения тегов у ученика удаляются вместе с учеником при полном сбросе (`IdentityDataReset`).
- Теги групп, несколько текстов у одного тега, история значений и подсказки ИИ к отдельным значениям не входят в решение.
