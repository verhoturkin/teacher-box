# ADR-0043. Системные промты ИИ-помощника редактирует учитель

- Статус: принято
- Дата: 2026-10-13
- Дополняет: [ADR-0006](0006-ai-integration.md)

## Контекст

По ADR-0006 промты — версионируемые ресурсы модуля `ai` (`ai/prompts/*.txt`). Системный промт задаёт тон и правила
черновиков: как оформлять задание, как писать отзыв, какую ставить оценку. Учитель видит черновики каждый день, но
поменять эти правила мог только разработчик с новой версией портала. Так у каждого репетитора свой стиль
(язык, длина, строгость), а библиотека промтов (0.13.x) меняет только запрос, не правила.

## Решение

1. Таблица `ai.system_prompts` (`feature` — ключ, `text` до 10 000 символов, `updated_at`, `version`) хранит
   промты учителя: строка есть, только если промт изменён.
2. `SystemPrompts.text(feature)` — текст учителя или стандартный из ресурса (`homework-draft.system.v3`,
   `review-draft.system.v1`). Текст учителя идёт к модели как есть, без подстановок `{{…}}`.
3. REST учителя: `GET /api/teacher/ai/system-prompts` (оба промта: текст, стандартный текст, изменён ли, версия),
   `PUT …/{feature}` `{text, version}` с оптимистической блокировкой (у стандартного версия 0),
   `DELETE …/{feature}` — вернуть стандартный. Администратор промты не видит.
4. Пользовательские промты (`*.user.*`) с данными задания и ответом ученика остаются ресурсами: их структура
   (теги `<request>`, `<answer>`) — часть защиты от подсказок внутри ответа.
5. Формат ответа (JSON-схема) задаётся отдельно от текста, поэтому правка промта не ломает разбор ответа. Полный сброс
   данных удаляет и изменённые промты.

## Последствия

- Новая версия стандартного промта в ресурсах не меняет промт, который учитель уже переписал; вернуть стандартный —
  одна кнопка.
- Учитель может убрать из промта проверки отзыва указание не выполнять просьбы из ответа ученика; в `<answer>`
  ответ остаётся данными, а черновик учитель всё равно читает перед отправкой.
