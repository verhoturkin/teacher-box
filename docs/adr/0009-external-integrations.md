# ADR-0009. Внешние интеграции: исходящий прокси и настройки

- Статус: принято
- Дата: 2026-09-26

## Контекст

Портал часто работает в России: Telegram Bot API там заблокирован, API Anthropic, OpenAI и
Gemini не обслуживают российские адреса. У учителя на сервере может быть прокси с VPN.
ВКонтакте и MAX, наоборот, должны ходить напрямую — российские сервисы могут не принимать
зарубежные адреса.

## Решение: исходящий прокси

- Прокси задаётся **отдельно для каждой интеграции**: `TEACHERBOX_NOTIFICATIONS_TELEGRAM_PROXY`,
  `TEACHERBOX_AI_PROXY` (позже — Google Календарь). Общего «прокси для всего» нет, чтобы
  российские сервисы не пошли через VPN.
- Формат — `http://host:port` или `socks5://host:port`. Разбор и проверка — `shared.http.OutboundProxy`;
  неверный адрес останавливает запуск с сообщением о переменной.
- **Прокси с логином и паролем не поддерживаются.** JDK запрещает Basic-аутентификацию при
  туннелировании HTTPS через HTTP-прокси (`jdk.http.auth.tunneling.disabledSchemes`), а
  SOCKS-аутентификация в `java.net` работает только через глобальный `Authenticator`.
  Обход — глобальные настройки JVM, влияющие на всё приложение. Типичный прокси для портала
  работает на том же сервере или в соседнем контейнере и слушает закрытый адрес, пароль ему
  не нужен.
- HTTP-клиенты для `RestClient` создаёт `shared.http.OutboundHttp`: без прокси — JDK
  `HttpClient` (HTTP/1.1), с прокси — `HttpURLConnection` с `java.net.Proxy`, потому что JDK
  `HttpClient` не умеет SOCKS. Тела запросов буферизуются (`Content-Length`). Адрес прокси не
  разрешается заранее — контейнер прокси может получить новый адрес после перезапуска.
- Anthropic SDK (OkHttp) получает тот же `java.net.Proxy` через `proxy(...)`.
- Связь с мессенджерами видна учителю: `MessengerHealth` запоминает результат последнего
  запроса long polling (`PENDING` / `OK` / `ERROR` с текстом ошибки), «Настройки» показывают его.
- Контейнеру backend добавлен `host.docker.internal` (`extra_hosts: host-gateway`), чтобы прокси
  на хосте был доступен по имени на любой ОС.

## Последствия

- Для прокси с паролем нужен промежуточный прокси без пароля на сервере (например, тот же xray
  или sing-box с локальным входом).
- Через прокси — HTTP/1.1 на `HttpURLConnection`; для long polling и редких запросов к ИИ этого
  достаточно.
