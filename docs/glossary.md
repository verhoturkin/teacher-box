# Словарь интерфейса

Одно понятие — одно слово в вебе, боте, уведомлениях и справке (аудит интерфейса 2026-09-29, DA-035). Тексты
новых экранов сверяются с этой таблицей; отступления — только с записью здесь.

| Понятие | Слово | Не используем |
|---|---|---|
| Занятие в расписании | занятие | «урок» (кроме кнопок «Начать урок» / «Войти в урок» и «ссылка на урок»), «сессия» |
| Вход на видеовстречу | учителю — «Начать урок», ученику — «Войти в урок» (в строке, листе, на главной) | «Подключиться», «Войти на урок» |
| Видеовстреча | видеовстреча, ссылка на видеовстречу (внешняя видеосвязь: Телемост, Zoom…) | «онлайн-урок» |
| Звонок в портале | звонок; «Звонки» (раздел учителя); «Войти» (в окне перед входом и на карточке комнаты), «Выйти из звонка» | «конференция», «созвон», «Завершить» для своего выхода |
| Комната звонка | комната — встроенная, своя у каждого ученика и группы («Комната пуста», «В звонке: …», «Ждут: N») | «комната» для внешней ссылки |
| Окно звонка | «Свернуть» / «Развернуть», «Переместить окно звонка», «Показ экрана», «Устройства», «Включить звук» | «Свернуть в трей», «Демонстрация» |
| Домашнее задание | «Задания» (меню, заголовок, вкладка, справка) | «Домашние задания» в меню и заголовке |
| Сданное учеником | работа — сданное целиком, ответ — одна попытка; кнопка — «Отправить на проверку» | «Сдать» |
| Возврат работы | «На доработке» (статус), «Вернуть на доработку» (действие) | «Нужно доработать» |
| Ответ на запрос ученика | «Согласовать» / «Отклонить» (на сайте, в справке) | «Принять перенос» |
| Регулярные занятия | регулярные занятия | «серия», «регулярное расписание», «регулярные уроки» |
| Закрыть окно | «Отмена» (форма, подтверждение), «Закрыть» (окно только сообщает) — ADR-0026 | «Назад» в окне, красная «Отмена» |
| Снять начисление | «Снять начисление» (история оплат) | «Отменить занятие» в истории оплат |
| Отменить занятие | «Отменить занятие…» (расписание) | «Отменить», «Удалить занятие» |
| Правка | «Изменить» («Изменить ученика», «Изменить задание») | «Редактировать», «Редактирование» |
| Следующий шаг мастера | «Далее» | «Дальше» |
| Цена | «Цена занятия» | «Стоимость занятия» |
| Долг | «долг» | «задолженность» |
| Кто ведёт | «учитель» | «преподаватель» |
| Оплата | «Оплата» (кнопка), «Записать оплату» (подсказка и имя значка) | «Принять оплату» |
| Администратор | «это настраивает администратор портала» — без имён переменных окружения (они — в справке администратора) | «TEACHERBOX_…» в интерфейсе учителя |
| Месяц отчёта | «сентябрь 2026 г.» | «2026-09» |
| Доска | «Доски» (раздел учителя), «Мои доски» (ученик); виды — «Доска Excalidraw» (своя, в портале) и «Внешняя доска» (по ссылке, например Холст) | «Доска Холст», «Холст» как общее название досок |
| Учебник | «Учебники» (раздел учителя и ученика); виды — «Учебник», «Рабочая тетрадь», «Другое»; «Новый учебник», «Заменить файл»; страницы — «с. 1-3, 7» | «Материалы», «Пособия» как название раздела, «Книга» |
| Копия доски | «Резервные копии» (окно доски), «Ежедневная копия», «Копия учителя»; действия «Сделать копию», «Восстановить» | «Бэкап», «Снимок» |
| Сохранение доски | «Сохранено», «Сохранение…», «Нет связи — повторим»; «Вернуться к доскам» | «Синхронизировано», «Выйти» |

Форматы и числа:

- даты — `dd.MM.yyyy HH:mm` (событие), `dd.MM.yyyy` (день), `HH:mm` (время); технические таблицы администратора —
  `dd.MM HH:mm[:ss]`;
- число с существительным согласуется (`CountPipe`, `shared/text/plural.ts`): «1 токен», «22 токена», «5 токенов»;
  число и единица склеены неразрывным пробелом («1 МБ», «45 мин»);
- нулевой баланс — «0 ₽», не «0»;
- заголовок пустого состояния — без точки в конце.
