# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии —
[семантическое версионирование](https://semver.org/lang/ru/): несовместимые изменения данных
или настроек увеличивают MAJOR, новые возможности — MINOR, исправления — PATCH.

> Версии до 1.0 нумеруются с нуля. Выпуски, которые раньше назывались 1.0.0–1.9.0, переименованы:
> 1.0.0 → 0.0.1, остальные 1.X.Y → 0.X.Y (1.9.0 → 0.9.0); содержимое выпусков не изменилось.

## [0.47.1] — 2026-11-11

### Изменено

- Портал загружает меньше кода при открытии: в начальном наборе остаются только используемые
  компоненты темы, а расчёт собственных цветов загружается при необходимости. Стили календаря,
  звонка и досок загружаются со своими разделами.
- nginx отдаёт заранее сжатые файлы и повторно использует соединения с сервером. Backend
  запускается с AOT-кэшем JVM; из образа убраны лишние зависимости сервера звонков.
- Уведомления формируются в разделах, где произошло событие. Тексты, языки, получатели и каналы
  сохранены. **Перед обновлением** проверьте незавершённые события в журнале администратора:
  старые события для удалённых обработчиков уведомлений после обновления не доставятся.
  Уже созданные уведомления и их очередь доставки сохраняются.
- Справка разделена на статьи без изменения текстов; wiki содержит обзор и ссылки на справку.
  Добавлена галерея компонентов для разработки, уточнены правила и проверки для агентов.

### Исправлено

- E2E-проверка создания занятия из месячного календаря выбирает пустой день основного календаря,
  а не кнопку мини-календаря. Проверяется и дата открытого занятия.
- E2E-проверка теста с шестью типами вопросов сохраняет ответ на порядок элементов, даже если
  случайная начальная перестановка уже правильная. Этот случай проверяется на каждом запуске.
- E2E в CI использует Chrome, установленный на runner, без падающей установки системных пакетов.

## [0.47.0] — 2026-11-10

### Добавлено

- Настройки учителя живут в портале: часовой пояс, валюта, длительность занятия по умолчанию,
  правила занятий (поздняя отмена, напоминания, горизонт серий, напоминание о близком сроке
  задания), адрес и название портала, токены мессенджеров и клиенты Google меняются в
  «Настройках» и действуют сразу, без перезапуска.
- Администратор меняет технические настройки в «Настройках» без перезапуска: лимиты файлов в
  заданиях, прокси, время и срок хранения резервных копий, сеансы и защиту входа, параметры
  доставки сообщений. Расписание резервных копий — переключатель и время.
- Несколько подключений ИИ: Anthropic, Gemini, OpenRouter, DeepSeek и любой OpenAI-совместимый
  сервис, у каждого свои модели, ключ и прокси. Одна модель назначается основной, расход за месяц
  показан по моделям.
- Выбор модели рядом с кнопкой ИИ в заданиях, проверке и итоге занятия; выбор запоминается на
  устройстве.
- Новый мастер первого запуска: полноэкранный, с шагами «Пароль» → «Вы и портал» → «Время и
  оплата» → «Правила» → «Готово»; в каждом поле уже стоит рабочее значение, адрес портала можно
  проверить.

### Изменено

- Настройки учителя больше не читаются из `.env`: при первом запуске новой версии портал один
  раз переносит прежние значения в настройки, дальше переменные не действуют, и их можно удалить
  (администратор видит их в «Настройках» → «Перенесено в настройки учителя»). Перестали
  читаться: `TEACHERBOX_TIMEZONE`, `BILLING_CURRENCY`, `BILLING_DEFAULT_LESSON_DURATION`,
  `SCHEDULE_DEFAULT_DURATION`, `SCHEDULE_LATE_CANCELLATION`, `SCHEDULE_REMINDERS`,
  `SCHEDULE_HORIZON`, `HOMEWORK_DUE_SOON_WINDOW`, `TEACHERBOX_PUBLIC_URL`,
  `IDENTITY_TEACHER_NAME`, токены Telegram, VK и MAX, `SCHEDULE_GOOGLE_CLIENT_*`,
  `BACKUP_GOOGLE_CLIENT_*` и все `AI_*` (кроме прокси). Домен по умолчанию остаётся из
  `TEACHERBOX_DOMAIN`. Подробнее — в вики, «Обновление».
- Переменные администратора (лимиты, прокси, сеансы, резервные копии) остаются необязательными:
  значение из портала важнее `.env`. Установщик больше не спрашивает часовой пояс.
- «С чего начать» на главной: убран шаг «Цена занятия» (её спрашивает мастер), добавлен
  «Подключить ИИ».

## [0.46.0] — 2026-11-03

### Добавлено

- Теги учеников: в «Настройки» → «Ученики» учитель заводит теги — со списком значений
  («Уровень английского» A1–C2, «Класс» 1–11) или со свободным текстом («Интересы»). Есть
  готовые шаблоны. Значение ставится в карточке ученика на новой вкладке «Теги». Теги видит только
  учитель: ученик, боты и администратор их не получают.
- Список учеников фильтруется по значению тега (чип «Теги»).
- ИИ-помощник учитывает теги с отметкой «Учитывать в ИИ» при черновиках заданий, тестов и
  проверки: это значения по умолчанию, а то, что учитель написал в запросе, важнее. Над запросом
  видны чипы «Учитываю об учениках»: любой можно убрать для одного запроса, а если у получателей
  разные значения, выбрать одно.

### Исправлено

- Открытое задание на очень широком окне: колонка учеников идёт сразу за колонкой задания, без
  пустого места между ними.
