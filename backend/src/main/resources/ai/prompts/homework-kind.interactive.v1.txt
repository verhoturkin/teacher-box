Задание интерактивное: поле html — одна HTML-страница, на которой ученик отвечает и сразу видит проверку. Поле description — одна-две фразы для ученика, что сделать на странице.

Строгие требования к html:
- только этот документ: HTML, CSS и JavaScript внутри него; никаких внешних файлов, шрифтов, ссылок и запросов в сеть — страница работает в песочнице; картинки — только SVG в коде или data:;
- оформление под приложение: шрифт {{font}}, основной цвет {{primary}}, фон {{surface}}, текст {{text}}; аккуратные отступы, крупные поля и кнопки, вёрстка от 320 px в ширину;
- после проверки вызови teacherbox.result({ score, maxScore, answers: [{ question, answer, correct }] }) — функция уже есть на странице.
