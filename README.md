# Teacher Box

Портал репетитора, который работает на вашем сервере: ученики, расписание, домашние задания,
оплаты и уведомления в одном месте — на компьютере и с телефона.

- **Один портал — один учитель.** Регистрации «с улицы» нет: ученики входят по
  ссылке-приглашению от учителя и видят только своё.
- **Данные у вас.** Всё хранится на вашем сервере или NAS в одном каталоге; резервные копии
  делаются каждую ночь.
- **Российские сервисы из коробки.** Уведомления в Telegram, ВКонтакте и MAX, видеовстречи в
  Яндекс Телемосте, свои доски для рисования вместе с учеником; ИИ-помощник — по желанию.

## Возможности

### Учителю

- **Главная** — быстрые действия (занятие, оплата, ученик, задание), следующее занятие с кнопкой
  «Начать урок», занятия на сегодня с быстрыми отметками, «Требует внимания» (неотмеченные
  занятия, работы на проверку, запросы переноса, сбои доставки), финансы и чек-лист первого
  запуска.
- **Ученики и группы** — приглашения по ссылке, отключение и возврат доступа, сброс пароля; группы
  со своей ценой занятия.
- **Расписание** — разовые и регулярные занятия с учеником или группой, перенос
  перетаскиванием, посещаемость, отмена, восстановление отменённого и удаление ошибочного
  занятия, нерабочее время учителя (разовое и еженедельное), запросы учеников на перенос и
  отмену, напоминания, календарь по ссылке (ICS) и синхронизация с Google Календарём.
- **Оплаты** — занятия списываются по отметке «Проведено» или «Пропуск», оплаты, баланс и долги
  каждого ученика, отчёт за месяц; цена занятия — общая, своя у ученика или у группы.
- **Домашние задания** — задания в Markdown с файлами, очередь проверки, оценки и возврат на
  доработку, напоминания о сроке.
- **Звонки и доски** — видеозвонки прямо в портале: своя комната у каждого ученика и группы,
  окно звонка сворачивается, пока вы работаете с доской или заданиями (или ссылка на Телемост,
  Zoom и др.); свои доски Excalidraw прямо в портале (рисуете вместе с учениками, доска сохраняется
  сама, есть резервные копии) или внешние доски по ссылке (например, Холст); кнопка «На доску» для
  заданий.
- **Уведомления** — колокольчик в кабинете, Telegram, ВКонтакте и MAX; через бота можно отметить
  занятие, ответить на запрос, записать оплату.
- **ИИ-помощник** (по желанию) — черновики заданий и проверок: Claude, Gemini или любой
  OpenAI-совместимый сервис, в том числе локальная модель.
- **Оформление** — Material 3 Expressive: светлая и тёмная тема, вся цветовая схема строится из цвета
  портала (готового или своего), свой логотип. Разделы — в панели слева на компьютере, в узкой
  панели на планшете и в нижней панели на телефоне; на телефоне главное действие раздела — кнопка
  внизу справа, списки — карточками, расписание — списком по дням. Кнопки, заголовки и списки во
  всех разделах устроены одинаково; подтверждения — зелёные, отмена и удаление — красные.
- **Резервные копии** — каждую ночь и по кнопке, скачивание, восстановление из интерфейса;
  полный сброс с копией перед ним.

### Ученику

- Ближайшее занятие с кнопкой «Войти в урок», задания со сроками и баланс на главной.
- Своё расписание и время, когда учитель занят (без имён других учеников); запрос на перенос или
  отмену — на занятое время перенести нельзя; «Не приду» на групповое занятие.
- Сдача заданий с файлами, оценки и комментарии учителя; «Мои доски» — рисует вместе с учителем.
- Уведомления в кабинете и в мессенджере; через бота — расписание, перенос, отмена, баланс.

### Администратору (по желанию)

Отдельный вход для того, кто помогает с сервером: поиск по журналу, состояние, проверка
интеграций, резервные копии, все настройки портала в интерфейсе (с перезапуском) и архив для
разработчика — без доступа к данным учеников (см. [docs/operations.md](docs/operations.md)).

Во всех разделах есть простая пошаговая справка: меню с именем → «Справка» или значок «?» рядом
с заголовком.

## Что нужно

- Сервер, компьютер или NAS с **Docker** и **Docker Compose v2**, около **1 ГБ** свободной памяти
  и немного места на диске (база, файлы заданий и копии).
- Для учеников снаружи — адрес портала в интернете с **HTTPS** (свой домен и, например, Caddy
  перед порталом, см. ниже). Для пробы достаточно `http://localhost`.
- Современный браузер: Chrome, Edge, Firefox, Safari — на компьютере и телефоне.

## Установка за 5 минут

Портал ставится из готовых образов — исходники и сборка на сервере не нужны. Нужны только два файла:

```bash
mkdir teacher-box && cd teacher-box
curl -fsSLO https://raw.githubusercontent.com/verhoturkin/teacher-box/main/compose.yaml
curl -fsSL https://raw.githubusercontent.com/verhoturkin/teacher-box/main/.env.example -o .env
```

Откройте `.env` и задайте хотя бы:

```ini
TEACHERBOX_IDENTITY_TEACHER_PASSWORD=придумайте-надёжный-пароль
TEACHERBOX_PUBLIC_URL=https://school.example.com   # адрес портала (можно задать и в «Настройках»)
TEACHERBOX_TIMEZONE=Europe/Moscow
```

Запустите:

```bash
docker compose up -d
```

Откройте `http://<адрес-сервера>:8080` и войдите как `teacher` с паролем из `.env`
(если пароль не задан, он сгенерирован и напечатан в журнале:
`docker compose logs backend | grep "Teacher account"`).

Портал — это два контейнера: `frontend` (nginx: интерфейс, передача запросов к API и к серверу
звонков) и `backend` (приложение и данные). Наружу открыт только `frontend`. Образы
`ghcr.io/verhoturkin/teacher-box-backend` и `-frontend` собраны для `amd64` и `arm64` (в том числе
Raspberry Pi и NAS на ARM); версию задаёт `TEACHERBOX_VERSION` в `.env` (по умолчанию `latest` —
последний выпуск).

**Сборка из исходников** (для разработки или своих изменений): в клоне репозитория
`docker compose -f compose.yaml -f compose.build.yaml up -d --build`.

### HTTPS

Портал рассчитан на работу за HTTPS. Проще всего поставить перед ним [Caddy](https://caddyserver.com)
— он сам получит сертификат:

```
school.example.com {
    reverse_proxy localhost:8080
}
```

Если прокси работает на том же сервере, откройте порт портала только для него:
`TEACHERBOX_HTTP_PORT=127.0.0.1:8080` в `.env` — тогда снаружи портал доступен лишь через HTTPS.

### NAS

На Synology/QNAP/TrueNAS с Docker используйте тот же `compose.yaml`: создайте проект
(«Container Manager» → «Проект» на Synology), положите в его каталог `compose.yaml` и `.env`.
Данные хранятся в Docker-томе `teacherbox-data`.

## Первые шаги

1. **Первоначальная настройка** откроется после первого входа: свой пароль вместо созданного
   автоматически, ваше имя, название и адрес портала, цена занятия. Её можно пропустить и
   поменять всё позже в «Настройках» и «Оплатах».
2. **Ученики** → «Добавить ученика»: портал покажет ссылку-приглашение — отправьте её ученику в
   мессенджере. По ссылке ученик сам задаёт логин и пароль. Кто занимается вместе, соберите в
   группу (карточка «Группы» в разделе «Ученики»).
3. **Расписание** → «Занятие» или «Регулярные занятия». После урока отметьте «Проведено» или
   «Пропуск» — занятие спишется с баланса ученика по его цене.
4. **Уведомления** → «Мессенджеры» → «Подключить»: мастер поможет создать бота, и напоминания и
   запросы учеников будут приходить вам и ученикам в Telegram, ВКонтакте или MAX.
5. **По желанию:** видеовстречи и доски у учеников, Google Календарь, ИИ-помощник, свой цвет и
   логотип («Настройки»).
6. **Проверьте копии:** «Настройки» → «Резервные копии» → «Создать копию сейчас» и скачайте её.

На главной странице список «С чего начать» показывает, что ещё осталось.

## Обновление

В каталоге с `compose.yaml`:

```bash
curl -fsSLO https://raw.githubusercontent.com/verhoturkin/teacher-box/main/compose.yaml
docker compose pull
docker compose up -d --remove-orphans
```

Первая команда берёт свежий `compose.yaml` (в новых версиях он может измениться), вторая скачивает
новые образы. Если портал собран из исходников — `git pull` и
`docker compose -f compose.yaml -f compose.build.yaml up -d --build --remove-orphans`.

**Переход с `compose.split.yaml` (до 1.9.0).** Файл переименован в `compose.yaml` и берёт готовые
образы; проект и том данных (`teacherbox-data`) те же. В клоне репозитория выполните `git pull` и
`docker compose up -d --remove-orphans`, старые локальные образы можно удалить:
`docker image prune`. Клон больше не нужен: достаточно перенести `compose.yaml` и `.env` в любой
каталог и запускать команды оттуда.

**Переход с `compose.single.yaml` (до 1.8.1).** Вариант «один контейнер» убран, данные остаются в
том же томе `teacherbox-data`. Обновитесь командами выше: `--remove-orphans` остановит и удалит
старый контейнер `app`, вместо него запустятся `backend` и `frontend`. Если перед порталом стоит
свой прокси с правилом `/livekit/` на `127.0.0.1:7880`, уберите это правило — теперь его выполняет
nginx контейнера `frontend`.

Перед обновлением сделайте резервную копию («Настройки» в меню пользователя → «Резервные копии» →
«Создать копию сейчас») и скачайте её. Миграции базы применяются автоматически при старте. Что
изменилось и что проверить после обновления — [CHANGELOG.md](CHANGELOG.md).

## Резервные копии и восстановление

Копии создаются каждую ночь в `/data/backups` (последние 7). Создать, скачать или восстановить
копию — «Настройки» → «Резервные копии» (администратору — раздел «Копии», без скачивания).
Перед восстановлением портал сам делает копию текущего состояния и перезапускается. «Полный
сброс» в «Настройках» удаляет все данные, кроме входа учителя и администратора и резервных копий
(перед ним тоже делается копия). Подробно — [docs/operations.md](docs/operations.md).

## Мессенджеры

Уведомления всегда видны в личном кабинете. Мессенджеры подключаются по желанию: «Уведомления» →
«Мессенджеры» → «Подключить». Мастер подскажет, как создать бота, проверит токен, подключит ваш
аккаунт и пришлёт тестовое сообщение — перезапускать портал не нужно. Боты получают сообщения
сами (long polling) — публичный адрес для вебхуков не нужен. Ученики подключают мессенджер у
себя в разделе «Уведомления»; кто уже подключил, видно в секции «Ученики», там же можно
напомнить остальным. В секции «Что присылать» каждый выбирает темы уведомлений для мессенджеров
и тихие часы.

Токены можно задать и переменными окружения (ниже) — тогда они важнее настроек из интерфейса.

**Telegram**

1. Напишите [@BotFather](https://t.me/BotFather) команду `/newbot`, задайте имя и адрес бота.
2. Вставьте токен в мастер (или в `TEACHERBOX_NOTIFICATIONS_TELEGRAM_BOT_TOKEN`).

**ВКонтакте** (сообщения от имени сообщества)

1. Создайте сообщество (можно закрытое) → «Управление» → «Сообщения»: включите.
2. «Работа с API» → «Ключи доступа»: создайте ключ с правом «Сообщения сообщества» — это
   токен (`TEACHERBOX_NOTIFICATIONS_VK_TOKEN`).
3. «Работа с API» → «Long Poll API»: включите, версия API 5.199, в «Типах событий» отметьте
   «Входящее сообщение».
4. «Сообщения» → «Настройки для бота»: включите «Возможности ботов» — иначе под сообщениями не
   будет кнопок меню.
5. Номер сообщества — цифры из `club123456` (`TEACHERBOX_NOTIFICATIONS_VK_GROUP_ID`).

**MAX**

1. Создайте бота на платформе MAX для партнёров ([dev.max.ru](https://dev.max.ru)).
2. Токен бота — в мастер (или в `TEACHERBOX_NOTIFICATIONS_MAX_TOKEN`).

Чтобы ссылки в сообщениях вели на портал, задайте адрес портала: «Настройки» → «Портал» (или
`TEACHERBOX_PUBLIC_URL`).

**Действия через бота.** Кроме уведомлений, бот показывает меню кнопками: напишите ему `/menu`.
`/cancel` отменяет начатое действие, `/help` — подсказка, `/stop` отключает уведомления. Если к
одному чату подключено несколько учеников (например, у родителя), бот спросит, от чьего имени
действовать. Перед любым изменением бот просит подтверждение.

Ученику бот показывает расписание со ссылкой на ближайший урок, ссылки на видеовстречи и доски,
баланс и последние оплаты; через бота ученик просит отменить или перенести занятие (выбирает
занятие, новый день и время, пишет комментарий), в групповом занятии сообщает «не приду», видит
ответы учителя на свои запросы и может отозвать запрос без ответа.

Учителю бот показывает занятия на сегодня и прошедшие без отметки — их можно отметить
(«Проведено», «Пропуск», у группы — кто был); запросы учеников — принять (позднюю отмену —
засчитать как пропуск или нет) или отклонить с ответом, кнопки есть и прямо под уведомлением о
запросе; через бота учитель записывает оплату (1, 4 или 8 занятий по цене ученика или любую сумму)
и добавляет в журнал занятие, проведённое вне расписания, — с учеником или с группой. Что умеет бот, видно в секции
«Мессенджеры»; там же можно выключить управление порталом через бота для учителя (уведомления
продолжат приходить). Подробнее — [ADR-0013](docs/adr/0013-bot-dialogs.md).

## Расписание и календари

В разделе «Расписание» учитель планирует разовые и регулярные занятия (например, по вторникам и
четвергам в 18:00), переносит их перетаскиванием и отмечает итог — проведённое или пропущенное
занятие само попадает в «Оплаты». Отменённое занятие можно восстановить, а ошибочное (ещё не
проведённое) — удалить. Кнопка «Нерабочее время» отмечает, когда учитель не работает: один раз
(отпуск, визит к врачу) или каждую неделю (обед, выходной). Ученик видит свои занятия и серым —
время, когда учитель занят или не работает (без имён других учеников); он может попросить перенос
на свободное время или отмену, учитель согласует или отклоняет. Напоминания приходят за сутки и за час
(`TEACHERBOX_SCHEDULE_REMINDERS`), отмена позже чем за сутки считается поздней
(`TEACHERBOX_SCHEDULE_LATE_CANCELLATION`).

**Группы.** В разделе «Ученики» (карточка «Группы» под списком учеников) учитель собирает группу
и задаёт цену занятия — она списывается с каждого участника. Занятие или регулярное расписание можно назначить группе; после
урока учитель отмечает, кто был («был», «пропуск» — оплачиваются, «предупредил» — нет). Ученик
группы может заранее нажать «Не приду» — учитель сразу получит уведомление, пропуск не спишется;
поздний отказ учитель рассматривает как запрос.

**Календарь на телефоне.** В разделе «Расписание» → «Получить ссылку»: секретная ссылка
подписки для Google, Apple или Яндекс Календаря — у учителя все занятия, у ученика свои.

**Google Календарь учителя** (мгновенная синхронизация вместо подписки) — «Настройки» →
«Google Календарь», там же пошаговая инструкция:

1. В [Google Cloud Console](https://console.cloud.google.com/) создайте проект и включите
   Google Calendar API.
2. В «Google Auth Platform» выберите тип External, добавьте себя в тестовые пользователи и
   нажмите «Publish app» — иначе Google отзывает доступ через 7 дней. Предупреждение
   «приложение не проверено» для личного использования можно пропустить.
3. Создайте OAuth-клиент типа «Web application» с адресом перенаправления
   `https://<адрес портала>/api/public/schedule/google/callback`.
4. Вставьте Client ID и Client secret в настройках портала (или задайте
   `TEACHERBOX_SCHEDULE_GOOGLE_CLIENT_ID` / `_SECRET`) и нажмите «Подключить Google».

Портал создаёт в вашем Google Календаре отдельный календарь «Teacher Box» и работает только с
ним; по желанию показывает в расписании занятость из вашего основного календаря. Для
перенаправления нужен HTTPS-адрес портала; без него подключите календарь один раз, открыв
портал по `http://localhost` (например, через SSH-туннель).

## Звонки и видеовстречи

**Звонки в портале.** У каждого ученика и каждой группы — своя постоянная комната, звонок идёт прямо
в браузере (один на один и группой, показ экрана). Раздел «Звонки» у учителя показывает, кто уже в
комнате; окно звонка можно свернуть в угол и продолжать работать в портале. Ссылка на комнату
попадает в занятия, напоминания, календари и бота. Нужен сервер звонков LiveKit — контейнер
`livekit` в compose-файлах (профиль `calls`): задайте `TEACHERBOX_MEETINGS_LIVEKIT_API_KEY` /
`_API_SECRET`, `COMPOSE_PROFILES=calls` и откройте порты для медиа — пошагово в
[эксплуатации](docs/operations.md#видеозвонки-livekit).

**Внешняя ссылка.** Вместо комнаты портала у ученика или группы может быть постоянная ссылка на
внешнюю видеосвязь (Телемост, Zoom и любая другая по https) — одна на все уроки. Её задают в разделе «Ученики» (строка
«Видеовстреча» в карточке ученика или группы); ссылка попадает в карточку занятия, напоминания,
календари и кнопку «Войти в урок» у ученика. В отдельном занятии можно указать другую ссылку.
Кнопка «Отправить ученику» пришлёт ссылку в кабинет и мессенджеры.

**Приложение на компьютере.** На Windows «Начать урок» открывает ссылку Телемоста в приложении
Телемоста (его нужно установить с [telemost.yandex.ru](https://telemost.yandex.ru)); стрелка справа на
кнопке открывает меню с пунктом «Открыть в браузере». Выбор хранится на устройстве: «Настройки» → «Видеовстречи» →
«Открывать встречи Телемоста в приложении на этом компьютере».

## Доски

Раздел «Доски» в меню учителя. Доска бывает двух видов:

- **Доска Excalidraw** — своя доска портала. Открывается на весь экран, сохраняется сама, учитель и
  ученики рисуют на ней одновременно в реальном времени: штрихи других появляются сразу, видны их
  курсоры и имена. Картинки хранятся в портале. Внешнего интернета не нужно. Если перед порталом
  стоит свой прокси, он должен пропускать WebSocket (см. [эксплуатацию](docs/operations.md)).
- В меню доски (☰): тема («Светлая», «Тёмная», «Как в системе»), сетка, колесо мыши — «Масштаб»
  (по умолчанию) или «Прокрутка (тачпад)».
- **Внешняя доска** — доска в другом сервисе (например, [Холст](https://app.holst.so) или Miro):
  портал хранит только её название и ссылку и открывает её в новой вкладке.

1. «Доски» → «Новая доска»: вид, название, ученики и группы (сколько угодно; ссылка — только для
   внешней доски).
2. Ученик видит доски — свои и своих групп — в разделе «Мои доски», на главной и в расписании.
   Ушёл из группы — доска группы ему больше не видна. В строке ученика или группы в «Учениках» —
   ссылка «Доски (n)», в карточке занятия — ссылки на доски его ученика или группы.
3. Из доски — «← Доски» вверху или «Вернуться к доскам» в меню: всё сохранится перед выходом.

**Резервные копии доски.** Раз в сутки портал копирует каждую изменённую доску Excalidraw (хранятся
последние 7 ежедневных копий), учитель может сделать свою копию (до 20 на доску): «Доски» → значок
копий в строке или «Резервные копии» на самой доске. «Восстановить» сначала сохраняет текущий рисунок
копией — вернуть можно и его. Доски, их копии и картинки входят в общую резервную копию портала.
Когда делать ежедневные копии и сколько хранить — `TEACHERBOX_BOARDS_BACKUP_CRON` (по умолчанию в 3:00)
и `TEACHERBOX_BOARDS_BACKUP_KEEP` (7) в [.env.example](.env.example).

**«На доску».** На странице задания, в редакторе задания (в том числе с черновиком ИИ) и в
проверке работы (комментарий и оценка, черновик ИИ) есть кнопка «На доску»: выберите доску. Доска
Excalidraw откроется в новой вкладке, материал — текстом или картинкой — уже будет в центре. Для
внешней доски материал скопируется в буфер обмена, а доска откроется в новой вкладке — нажмите на ней
Ctrl+V; картинкой копирует, только когда портал открыт по https (или на `localhost`).

> При обновлении до 1.7.0 доски-ссылки прежних версий удаляются — добавьте нужные заново как
> внешние доски.

## ИИ-помощник

По умолчанию выключен. Включается в `.env` (или администратором в «Настройках»):

```ini
# Claude (Anthropic): ключ — на console.anthropic.com
TEACHERBOX_AI_PROVIDER=anthropic
TEACHERBOX_AI_API_KEY=sk-ant-...
# модель по умолчанию — claude-opus-5

# или Google Gemini: ключ Gemini API — на aistudio.google.com («Get API key»)
TEACHERBOX_AI_PROVIDER=gemini
TEACHERBOX_AI_API_KEY=AIza...
# модель по умолчанию — gemini-3.8-flash

# или OpenAI-совместимый сервис
TEACHERBOX_AI_PROVIDER=openai-compatible
TEACHERBOX_AI_BASE_URL=https://api.openai.com/v1     # OpenRouter: https://openrouter.ai/api/v1
TEACHERBOX_AI_API_KEY=sk-...
TEACHERBOX_AI_MODEL=gpt-5

# или локальная модель в Ollama (ключ не нужен)
TEACHERBOX_AI_PROVIDER=openai-compatible
TEACHERBOX_AI_BASE_URL=http://ollama:11434/v1
TEACHERBOX_AI_MODEL=qwen3:14b

TEACHERBOX_AI_MONTHLY_TOKEN_LIMIT=2000000
```

После перезапуска портала появятся кнопки «Сгенерировать с ИИ» в редакторе задания и «Черновик
проверки» на странице проверки. Тексты уходят провайдеру только по вашему нажатию; ответ ИИ
всегда черновик, который вы правите сами. Расход — на странице «ИИ».

Про Gemini: подписка Google AI Pro к порталу не подключается — она действует только в
приложении Gemini и в веб-интерфейсе AI Studio, а обращения программ к Gemini API оплачиваются
отдельно (есть бесплатный уровень с дневными лимитами). На бесплатном уровне Google может
использовать тексты запросов для улучшения своих продуктов, а в запросах на проверку бывают
ответы учеников — для них лучше включить оплату в AI Studio. Из России Gemini API недоступен,
нужен прокси (см. ниже).

## Прокси для Telegram и ИИ

Из России Telegram Bot API недоступен, а API Anthropic, OpenAI и Gemini не обслуживают
российские адреса. Если на сервере есть прокси с VPN, направьте через него только эти
интеграции (ВКонтакте и MAX всегда работают напрямую):

```ini
TEACHERBOX_NOTIFICATIONS_TELEGRAM_PROXY=socks5://host.docker.internal:1080
TEACHERBOX_AI_PROXY=socks5://host.docker.internal:1080
```

- Адрес прокси — `http://хост:порт` или `socks5://хост:порт`, без логина и пароля.
- Прокси на самом сервере виден из контейнера как `host.docker.internal`. Он должен слушать
  адрес, доступный контейнеру: адрес моста Docker (обычно `172.17.0.1`) или `0.0.0.0` с
  закрытым снаружи портом. Прокси, который слушает только `127.0.0.1`, из контейнера не виден.
- Прокси в соседнем контейнере (например, xray или sing-box) добавьте в тот же compose-проект
  и укажите имя сервиса: `socks5://vpn:1080`.
- Проверка: «Уведомления» → «Мессенджеры» (или «Настройки» → «Интеграции») — у Telegram должно
  быть «Работает»; текст ошибки связи показан там же и в журнале. Администратор может проверить
  связь со всеми сервисами сразу: «Интеграции» → «Проверить».

Без прокси на сервере можно указать свой адрес Bot API в
`TEACHERBOX_NOTIFICATIONS_TELEGRAM_API_URL` — например, реверс-прокси к `api.telegram.org` на
своём зарубежном VPS (через него проходит токен бота, поэтому только на своём сервере).

## Настройки

Все переменные с пояснениями — в [.env.example](.env.example). Администратор может менять их и в
интерфейсе («Настройки»): значения оттуда важнее `.env` и применяются после перезапуска портала.
Цену занятия, название, адрес, цвет и логотип портала учитель задаёт сам — в «Оплатах» и
«Настройках». Эксплуатация, безопасность, журналы и ресурсы — [docs/operations.md](docs/operations.md).

## Частые вопросы

**Учитель забыл пароль.** Задайте в `.env` новый `TEACHERBOX_IDENTITY_TEACHER_PASSWORD` и
`TEACHERBOX_IDENTITY_TEACHER_RESET_PASSWORD=true`, перезапустите портал
(`docker compose up -d`), войдите с новым паролем и верните
`TEACHERBOX_IDENTITY_TEACHER_RESET_PASSWORD=false`.

**Ученик забыл пароль.** «Ученики» → в строке ученика «Ссылка для сброса пароля»: портал покажет
ссылку — отправьте её ученику, по ней он задаст новый пароль.

**Ссылки в сообщениях и приглашениях ведут не туда.** Проверьте адрес портала: «Настройки» →
«Портал» (или `TEACHERBOX_PUBLIC_URL`). С него начинаются все ссылки.

**Не приходят сообщения в Telegram.** Из России Telegram Bot API недоступен — нужен
[прокси](#прокси-для-telegram-и-ии). Состояние связи видно в «Уведомления» → «Мессенджеры».

**Как перенести портал на другой сервер.** Скачайте свежую копию («Настройки» → «Резервные
копии»), установите портал на новом сервере, положите архив в `/data/restore/` и перезапустите
контейнер — копия восстановится при запуске ([docs/operations.md](docs/operations.md)).

**Портал не запускается после изменения настроек администратором.** Исправьте или удалите
значение в `config/settings.properties` в каталоге данных и перезапустите контейнер.

**Где хранятся данные и как начать заново.** Всё — в Docker-томе `teacherbox-data`: база, файлы
заданий, копии. «Настройки» → «Полный сброс» удаляет данные (кроме входа учителя и
администратора и копий), перед этим портал делает копию.

## Безопасность

- Данные учеников не покидают ваш сервер; наружу уходят только сообщения в подключённые
  мессенджеры и — по нажатию учителя — тексты для ИИ-помощника.
- Ученик видит только свои занятия, оплаты и задания; занятое время учителя — без имён.
- Администратор не видит данных учеников; его действия пишутся в журнал.
- Откройте портал в интернет только через HTTPS (см. [HTTPS](#https)).

## Разработка

- Backend: Java 25, Spring Boot 4, Spring Modulith, H2 (файловый режим)
- Frontend: Angular 21 LTS, PrimeNG 21 (MIT) с темой Material 3 Expressive, шрифт Roboto, TypeScript (strict)
- Поставка: Docker Compose — два контейнера (nginx и приложение)

Правила и архитектура — [AGENTS.md](AGENTS.md), решения — [docs/adr](docs/adr),
план — [docs/PLAN.md](docs/PLAN.md) (выполненные — в [docs/archive/plans](docs/archive/plans/README.md)).

```bash
cd backend && ./mvnw spring-boot:run          # API на :8080, данные в backend/data
cd frontend && npx -y npm@11 ci && npm start  # UI на :4200 с прокси /api
./scripts/verify.sh                           # все проверки (как pre-commit и CI)
./scripts/e2e.sh                              # сценарные тесты Playwright на свежем контейнере
```
